# Практическая работа № 1

## Тема: Построение адаптивных макетов с Bootstrap 5 — Layout, Flexbox и Grid

**Продолжительность:** 90 минут  
**Формат:** индивидуальная самостоятельная работа  
**Технологии:** HTML5, Bootstrap 5.3.5  
**Результат:** одна адаптивная HTML-страница с выполненными упражнениями и итоговым макетом

### Цель работы

Научиться создавать адаптивные страницы с помощью стандартной сетки Bootstrap и Flexbox-утилит: распределять ширину колонок, управлять переносами, выравнивать элементы и комбинировать несколько способов построения интерфейса.

### Что нужно знать перед началом

- Структуру `container → row → col`.
- Принцип 12-колоночной сетки и breakpoints `sm`, `md`, `lg`, `xl`.
- Классы `d-flex`, `flex-row`, `flex-column`, `justify-content-*`, `align-items-*`.
- Различие между `gap-*` для Flexbox и `g-*` для стандартной Bootstrap-сетки.
- Назначение `row-cols-*`, `col-auto`, `ms-auto`, `p-*` и `m-*`.

> **Важно:** стандартная сетка Bootstrap (`row`, `col`, `row-cols-*`) построена на Flexbox. Класс `d-grid` включает CSS Grid, но классы экспериментальной сетки `g-col-*` не работают в обычной CDN-сборке Bootstrap без специальной Sass-настройки. В этой работе используйте стандартную сетку Bootstrap.

## Подготовка проекта — перед началом заданий

1. Создайте папку `bootstrap-practice`.
2. Внутри создайте `index.html`.
3. Подключите Bootstrap 5.3.5 через CDN.
4. Откройте страницу в браузере; при необходимости используйте расширение Live Server.
5. В браузере откройте инструменты разработчика (`F12`) и включите режим эмуляции мобильных устройств.

**Стартовый шаблон:**

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Практическая работа — Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.5/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <main class="container py-4">
        <h1 class="mb-4">Bootstrap: Layout, Flexbox, Grid</h1>

        <!-- Размещайте выполненные задания здесь. -->

    </main>
</body>
</html>
```

**Общие правила:**

- Используйте **только готовые классы Bootstrap** для расположения, размеров, интервалов, цветов и оформления.
- Не пишите собственный CSS, атрибут `style` и JavaScript (для заданий они не нужны).
- Используйте подходящие HTML-теги: `header`, `main`, `section`, `aside`, `footer`, `nav`.
- Каждое задание оформите отдельной секцией с заголовком (`Задание 1`, `Задание 2` и т. д.).
- Проверяйте результат при ширине окна **390 px, 800 px и 1280 px**.
- Для цветных блоков внутри сетки помещайте фон и `p-*` во **внутренний** элемент колонки. Это помогает корректно показать gutters.

## Задание 1. Сетка из 12 колонок — 10 минут

**Тема:** `container`, `row`, `col`, `col-3`, `col-6`, `col-auto`.

**Что нужно сделать:** создайте внутри контейнера три независимые строки.

1. **Строка A:** три цветных блока с ширинами 25%, 50% и 25%.
2. **Строка B:** три блока: первый занимает 2 части из 12, третий — 4 части из 12, а второй автоматически занимает оставшуюся ширину.
3. **Строка C:** два блока, каждый занимает половину строки; ниже 768 px каждый блок должен занимать всю строку.
4. Добавьте видимые отступы между содержимым колонок.
5. В каждом блоке напишите его ширину или имя (`A1`, `A2` и т. д.).

**Ожидаемый результат:**

| Строка | Расположение на большом экране |
|---|---|
| A | 25% / 50% / 25% |
| B | 2/12 / оставшееся место / 4/12 |
| C | 50% / 50% |

**Проверка:** на экране 390 px блоки строки C идут один под другим, а на 800 px — рядом.

**Вопрос:** чем `col` отличается от `col-6`?

## Задание 2. Адаптивная галерея из шести карточек — 12 минут

**Тема:** `row-cols-*`, `col-*`, `g-*` и breakpoints.

**Что нужно сделать:** создайте галерею из шести карточек (`Фото 1` … `Фото 6`).

Требования:

- На экранах **меньше 768 px** — **1 карточка** в строке.
- На экранах **от 768 до 991 px** — **2 карточки** в строке.
- На экранах **от 992 px** — **3 карточки** в строке.
- Между карточками должен быть заметный одинаковый промежуток.
- Карточки должны иметь фон, внутренние отступы и закруглённые углы.
- Сделайте все карточки визуально аккуратными, даже если текст в одной из них длиннее.

**Подсказка:** попробуйте решить через `row-cols-*`; альтернативно можно указать адаптивную ширину каждому `col`.

**Проверка:** при 390 px — 6 строк, при 800 px — 3 строки, при 1280 px — 2 строки.

**Вопрос:** что удобнее при десяти одинаковых карточках — `row-cols-*` или повторение нескольких `col-...` у каждой карточки? Почему?

## Задание 3. Исправление промежутков между колонками — 10 минут

**Тема:** `gap-*`, `g-*`, `gx-*`, `gy-*`.

Дан фрагмент:

```html
<div class="row gap-2">
    <div class="col-6 text-bg-warning">Левая часть</div>
    <div class="col-6 text-bg-warning">Правая часть</div>
</div>
```

**Что нужно сделать:**

1. Вставьте фрагмент на страницу и посмотрите, как располагаются блоки.
2. Объясните, почему два элемента шириной по 50% могут не поместиться в одной строке при добавлении `gap-2`.
3. Исправьте разметку, используя механизм **gutters**, чтобы блоки оставались рядом и между их цветными областями был заметный промежуток.
4. Создайте ниже вторую строку из трёх равных колонок, установив **разные горизонтальный и вертикальный интервалы**.
5. Проверьте страницу на 390 и 1280 px.

**Ожидаемый результат:** две половины занимают одну строку, между цветными областями есть расстояние, горизонтальной прокрутки нет.

**Вопрос:** почему в стандартной сетке Bootstrap предпочтительнее `g-2`, а не `gap-2`?

## Задание 4. Шапка сайта на Flexbox — 12 минут

**Тема:** `d-flex`, `justify-content-*`, `align-items-*`, `gap-*`, `ms-auto`.

**Что нужно сделать:** постройте шапку сайта, состоящую из трёх групп:

- Слева — текстовый логотип `WEBSTORE`.
- В центре — ссылки `Главная`, `Каталог`, `Контакты`.
- Справа — кнопка `Войти`.

Требования:

1. На широком экране все группы должны находиться в одной строке.
2. Группы должны быть выровнены по вертикальному центру.
3. Между ссылками нужен одинаковый промежуток.
4. Распределите группы по ширине шапки **без** ручного задания пиксельных отступов.
5. Сделайте фон шапки тёмным, а текст — светлым.
6. Используйте хотя бы один из классов: `justify-content-between` или `ms-auto`.

**Проверка:** логотип остаётся слева, кнопка — справа; вертикальные центры элементов совпадают.

**Вопрос:** чем различаются `justify-content-between` и `align-items-center` при `flex-row`?

## Задание 5. Адаптивное направление Flexbox — 10 минут

**Тема:** `flex-column`, `flex-md-row`, адаптивное выравнивание.

**Что нужно сделать:** создайте блок с тремя действиями: `Скачать`, `Поделиться`, `Подробнее`.

Требования:

- На ширине **меньше 768 px** кнопки располагаются **вертикально**, одна под другой.
- Начиная с **768 px** кнопки располагаются **горизонтально**.
- На мобильном экране кнопки должны растягиваться на ширину блока либо быть одинаковыми по ширине.
- Между кнопками должен сохраняться одинаковый промежуток.
- Не используйте медиазапросы CSS.

**Проверка:** при изменении ширины окна на границе 768 px направление меняется автоматически.

**Вопрос:** зачем классы `flex-column` и `flex-md-row` используются вместе?

## Задание 6. Центрирование формы авторизации — 10 минут

**Тема:** `justify-content-center`, `align-items-center`, ширина через Bootstrap Grid, `d-grid`.

**Что нужно сделать:** создайте секцию с формой входа.

В форме должны быть:

1. Заголовок `Вход в личный кабинет`.
2. Поле `Email`.
3. Поле `Пароль`.
4. Кнопка `Войти`.

Требования:

- Секция имеет достаточную высоту, чтобы центрирование было заметно (можно использовать `min-vh-100`).
- Форма находится **по горизонтали и вертикали по центру секции**.
- На телефоне карточка формы почти полностью занимает доступную ширину контейнера.
- На большом экране форма заметно уже контейнера.
- Кнопка входа занимает всю ширину формы (один из вариантов — обёртка с `d-grid`).
- Все интервалы задаются утилитами Bootstrap.

**Проверка:** при 390 и 1280 px форма остаётся по центру, поля не выходят за границы блока.

**Вопрос:** почему одного `justify-content-center` недостаточно для центрирования по двум осям?
