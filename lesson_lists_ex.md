## Задание 12. Мини-проект «Корзина интернет-магазина»

**Сложность: ★★★★★**

Разработайте консольную программу для управления корзиной покупок.

Создайте два списка:

```python
products = []
prices = []
```

Первый список хранит названия товаров, второй — их цены. Элементы с одинаковыми индексами должны относиться к одному товару.

Программа должна работать в цикле `while` и предоставлять меню:

```text
=== КОРЗИНА МАГАЗИНА ===

1. Добавить товар
2. Показать корзину
3. Удалить товар
4. Найти товар
5. Показать общую стоимость
6. Показать самый дорогой товар
0. Выход
```

**Требования:**

1. При добавлении товара запросить его название и цену.
2. При просмотре корзины выводить порядковый номер, название и цену каждого товара.
3. При удалении товара пользователь вводит его порядковый номер. Необходимо удалить товар и соответствующую цену из обоих списков.
4. При поиске товара вывести его название, цену и номер позиции, если товар найден.
5. Вычислять общую стоимость всех товаров.
6. Определять самый дорогой товар.
7. Проверять корректность номера товара при удалении.
8. Предусмотреть пустую корзину и вывод соответствующих сообщений.
9. Завершать программу при выборе команды `0`.

**Дополнительные условия:**
- Запретите добавление товара с отрицательной ценой.
- При просмотре корзины выводите её содержимое в виде нумерованного списка.
- После каждого изменения корзины выводите количество товаров.
