# Домашнее задание по Python

## Тема: Словари (Dictionary)

**Цель:** закрепить навыки создания словарей, обращения к их элементам, перебора, сравнения и использования встроенных функций и методов.

### Задание 1. Информация о студенте

Создайте словарь `student`, который содержит следующую информацию:

- Имя;
- Возраст;
- Город проживания;
- Любимый предмет;
- Средний балл.

Выведите весь словарь, а затем каждое значение отдельно, обращаясь к нему по ключу.

### Задание 2. Создание словарей

Создайте словарь тремя разными способами:

- С помощью фигурных скобок `{}`.
- С помощью функции `dict()`.
- С помощью функции `dict()` на основе списка кортежей.

Во всех трёх словарях должна храниться следующая информация:

| Ключ | Значение |
|---|---|
| name | Python |
| year | 1991 |
| creator | Guido van Rossum |

Выведите каждый словарь и сравните их между собой.

### Задание 3. Список товаров

### Задание 4. Успеваемость ученика

Дан словарь с оценками ученика:

- Средний балл ученика.

### Задание 5. Телефонная книга

Дан словарь:

```python
contacts = {
    "Анна": "89001112233",
    "Максим": "89004445566",
    "Иван": "89007778899",
    "Ольга": "89001234567"
}
```

Пользователь вводит имя человека с клавиатуры.

Если имя присутствует в словаре, программа должна вывести его номер телефона. В противном случае вывести сообщение «Контакт не найден».

Используйте оператор `in`.

**Пример работы:**

```text
Введите имя: Иван
Номер телефона: 89007778899
```

### Задание 6. Перебор словаря

- Выведите каждую страну и её столицу, используя `items()` и распаковку пары.

**Пример вывода:**


### Задание 8. Сравнение словарей

Даны три словаря:

```python
student1 = {
    "name": "Алексей",
    "age": 15,
    "grade": 9
}

student2 = {
    "grade": 9,
    "name": "Алексей",
    "age": 15
}

student3 = {
    "name": "Алексей",
    "age": 16,
    "grade": 9
}
```

Выполните сравнение:

- `student1` и `student2`;
- `student1` и `student3`;
- `student2` и `student3`.

Выведите результаты сравнений. Объясните в комментариях к программе, влияет ли порядок расположения элементов на равенство словарей.

### Задание 12. Анализ продаж

Дан словарь с количеством продаж за неделю:

```python
sales = {
    "Понедельник": 15,
    "Вторник": 23,
    "Среда": 18,
    "Четверг": 30,
    "Пятница": 42,
    "Суббота": 50,
    "Воскресенье": 35
}
```

Напишите программу, которая:

- Выводит статистику продаж за каждый день.
- Вычисляет общее количество продаж за неделю.
- Вычисляет среднее количество продаж за день.
- Определяет самый успешный день.
- Определяет день с наименьшим количеством продаж.
- Выводит дни, в которые было совершено более 25 продаж.
- Проверяет наличие введённого пользователем дня недели в словаре и выводит соответствующее количество продаж.
