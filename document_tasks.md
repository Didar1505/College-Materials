# Практическая работа

**Тема:** Многостраничные документы. Структура документа. Гипертекстовые документы. Совместная работа над документом. Шаблоны.

**Продолжительность:** 90 минут

**Программы:** Microsoft Word, Google Документы.

## Задание 1. Создание многостраничного документа

**Время:** 25 минут

**Ситуация:** Вам поручили подготовить электронный справочник для новых студентов колледжа.

Создайте документ Word с названием **«Цифровой справочник студента»**.

### Требования к документу

**Страница 1. Титульный лист**

Разместите:

- Название учебного заведения.
- Название документа.
- ФИО и группу.
- Город и год.

**Страница 2. Оглавление**

Создайте автоматическое оглавление с помощью стилей заголовков.

**Страница 3 и далее. Основной текст**

Документ должен содержать следующие разделы:

**1. Организация учебных материалов**

- 1.1. Хранение файлов
- 1.2. Правила именования документов

**2. Инструменты для учёбы**

- 2.1. Текстовые редакторы
- 2.2. Облачные хранилища

**3. Информационная безопасность**

- 3.1. Надёжные пароли
- 3.2. Защита личных данных

В каждом подразделе напишите по 3–5 предложений.

### Дополнительные требования

1. Для названий разделов используйте стиль «Заголовок 1».
2. Для названий подразделов — «Заголовок 2».
3. Добавьте нумерацию страниц в нижнем колонтитуле.
4. В верхний колонтитул добавьте текст «Справочник студента».
5. Используйте разрывы страниц для отделения титульного листа и оглавления.
6. Добавьте минимум одно изображение по теме документа.
7. Настройте единый шрифт и оформление основного текста.
8. Убедитесь, что все заголовки отображаются в области навигации.

**Результат:** файл `Справочник_Фамилия.docx`, содержащий титульный лист, оглавление и структурированный основной текст.

## Задание 2. Создание гипертекстового документа

**Время:** 15 минут

**Ситуация:** Ваш электронный справочник должен стать интерактивным, чтобы читатель мог быстро переходить к нужной информации.

Продолжите работу с документом из задания 1.

### Часть А. Внешние гиперссылки

В раздел «Инструменты для учёбы» добавьте ссылки на следующие ресурсы:

| Название ссылки | Адрес |
|---|---|
| Microsoft Word | https://www.microsoft.com/microsoft-365/word |
| Google Документы | https://docs.google.com |
| Google Диск | https://drive.google.com |

Ссылки должны отображаться под указанными названиями, а не в виде длинных URL-адресов.

### Часть Б. Внутренние гиперссылки

1. В начале основного текста добавьте блок «Быстрая навигация».
2. Разместите в нём три пункта:
   - Перейти к организации учебных материалов.
   - Перейти к инструментам для учёбы.
   - Перейти к информационной безопасности.
3. Превратите каждый пункт в гиперссылку на соответствующий раздел.
4. В конце последнего раздела добавьте ссылку «Вернуться к началу справочника».

### Часть В. Изменение структуры

1. Добавьте новый подраздел «3.3. Двухфакторная аутентификация».
2. Напишите краткое описание из 3–4 предложений.
3. Обновите автоматическое оглавление.
4. Проверьте работу всех созданных гиперссылок.

**Результат:** интерактивный документ с работающими внутренними и внешними ссылками.

## Задание 3. Совместное редактирование документа

**Время:** 20 минут

**Формат:** работа в парах.

**Ситуация:** Вы вместе с одногруппником готовите правила использования компьютерного кабинета.

Создайте общий документ Google Документов **«Правила компьютерного кабинета»**.

### Этап 1. Первый участник

1. Создайте документ.
2. Добавьте заголовок «Правила компьютерного кабинета».
3. Создайте раздел «Перед началом работы».
4. Напишите минимум четыре правила поведения.
5. Предоставьте второму участнику доступ на редактирование.

### Этап 2. Второй участник

1. Откройте предоставленный документ.
2. Добавьте раздел «Во время работы».
3. Напишите минимум четыре правила.
4. Добавьте раздел «После завершения работы» с тремя правилами.
5. Выделите одно из правил и оставьте комментарий с предложением по улучшению.

### Этап 3. Совместная работа

Оба участника должны:

1. Одновременно открыть и редактировать документ.
2. Изменить формулировку одного из правил.
3. Обсудить предложенное исправление через комментарии.
4. Ответить хотя бы на один комментарий.
5. Проверить историю версий.
6. Убедиться, что изменения обоих участников сохранились.

### Этап 4. Проверка прав доступа

Первый участник должен:

1. Изменить права второго участника с «Редактор» на «Читатель».
2. Попросить его попробовать изменить документ.
3. Убедиться, что редактирование недоступно.
4. Вернуть первоначальные права доступа.

**Результат:** общий документ с правилами, комментариями и историей изменений.

## Задание 4. Создание собственного шаблона

**Время:** 15 минут

**Ситуация:** В течение учебного года вам предстоит сдавать много практических работ. Чтобы не оформлять каждый отчёт заново, создайте универсальный шаблон.

Создайте в Microsoft Word **«Шаблон отчёта о практической работе»**.

### Структура шаблона

**Титульный лист:**

- Название учебного заведения.
- Дисциплина: `[Название дисциплины]`
- Практическая работа № `[Номер]`
- Тема: `[Название темы]`
- Выполнил: `[ФИО студента]`
- Группа: `[Номер группы]`
- Проверил: `[ФИО преподавателя]`
- Город и год.

**Основная часть:**

**1. Цель работы**

`[Укажите цель практической работы]`

**2. Оборудование и программное обеспечение**

`[Перечислите использованные средства]`

**3. Ход выполнения работы**

`[Опишите последовательность выполненных действий]`

**4. Результаты**

`[Добавьте результаты и скриншоты]`

**5. Вывод**

`[Сформулируйте итог работы]`

### Требования

1. Оформите титульный лист.
2. Примените стили к заголовкам.
3. Добавьте нумерацию страниц.
4. Настройте одинаковые поля страницы.
5. Создайте места для вставки скриншотов.
6. Сохраните документ как шаблон Word (`.dotx`).
7. Создайте новый документ на основе сохранённого шаблона.
8. Заполните в нём ФИО, группу, номер и тему практической работы.

**Результат:** два файла:

- `Шаблон_отчета.dotx`
- `Отчет_пример.docx`

## Задание 5. Итоговое испытание «Исправь документ»

**Время:** 10 минут

**Ситуация:** Другой студент подготовил документ с ошибками оформления. Ваша задача — привести его в профессиональный вид.

Создайте новый документ Word и вставьте следующий текст:

**Компьютерные сети**

Компьютерная сеть объединяет устройства для обмена информацией.

**Виды компьютерных сетей**

Локальная сеть используется в пределах здания или небольшой территории.

Глобальная сеть объединяет компьютеры на больших расстояниях.

**Безопасность в сети**

Для защиты информации используют пароли, шифрование и другие средства безопасности.

**Полезные ресурсы**

Официальный сайт Cisco: https://www.cisco.com

### Задания

1. Сделайте «Компьютерные сети» заголовком первого уровня.
2. Оформите остальные три названия разделов заголовками второго уровня.
3. Добавьте автоматическое оглавление в начало документа.
4. Создайте гиперссылку «Перейти к безопасности» на соответствующий раздел.
5. Превратите название «Официальный сайт Cisco» во внешнюю гиперссылку.
6. Добавьте нумерацию страниц.
7. Добавьте новый раздел «Заключение» с двумя предложениями.
8. Обновите оглавление после добавления раздела.

**Результат:** оформленный документ `Исправленный_документ.docx`.
