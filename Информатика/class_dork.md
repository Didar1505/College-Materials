# Практические примеры Google Dorks

## Задание 1. Найти точную фразу

### Проблема

Нужно найти страницы, на которых встречается именно выражение:

**информационная безопасность**

Если написать:

```text
информационная безопасность
```

поисковик может показывать страницы, где эти слова находятся отдельно или используются похожие понятия.

### Dork

```text
"информационная безопасность"
```

### Что делает

Кавычки заставляют поисковик искать **точное словосочетание**.

То есть нас интересует именно:

```text
информационная безопасность
```

а не просто страницы, где отдельно встречаются слова:

```text
информационная
безопасность
```

# Задание 22. Постепенное улучшение одного запроса

### Проблема

Нужно найти качественный материал по фишинговым атакам.

Начинаем:

```text
фишинг
```

Слишком широко.

Добавляем:

```text
"фишинговые атаки"
```

Теперь точнее.

Далее:

```text
"фишинговые атаки" "методы защиты"
```

Теперь указали нужный аспект.

Далее:

```text
"фишинговые атаки" "методы защиты" filetype:pdf
```

Теперь только PDF.

Далее:

```text
"фишинговые атаки" "методы защиты" filetype:pdf after:2024-01-01
```

Теперь современные PDF-документы.

### Что демонстрирует пример

Каждый новый оператор **сужает пространство поиска**:

```text
Весь Интернет
      ↓
фишинг
      ↓
точная тема
      ↓
методы защиты
      ↓
PDF
      ↓
современные материалы
```

# Общая формула

Практически любой сложный запрос можно строить следующим образом:

```text
"ЧТО ИЩЕМ"
site:ГДЕ_ИЩЕМ
filetype:ФОРМАТ
after:ДАТА
before:ДАТА
-ЧТО_ИСКЛЮЧИТЬ
```

Например:

```text
site:nist.gov "network security" filetype:pdf after:2024-01-01 -blockchain
```

Поэтому главное, что должен понять студент:

```text
Google Dork
=
обычный поисковый запрос
+
точные условия поиска
```
