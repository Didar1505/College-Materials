## Расширенный поиск в Интернете и Google Dorks

### Краткая шпаргалка

| Оператор | Что делает | Пример |
|---|---|---|
| `"..."` | Ищет точную фразу | `"компьютерные сети"` |
| `-слово` | Исключает слово | `Python -snake` |
| `-site:` | Исключает сайт | `Linux -site:wikipedia.org` |
| `site:` | Ищет только на указанном сайте | `site:python.org asyncio` |
| `filetype:` | Ищет определённый тип файла | `filetype:pdf` |
| `after:` | Материалы после даты | `after:2025-01-01` |
| `before:` | Материалы до даты | `before:2026-01-01` |
| `intitle:` | Ищет слово в заголовке страницы | `intitle:Python` |
| `inurl:` | Ищет слово в URL страницы | `inurl:tutorial` |
| `intext:` | Ищет слово внутри текста страницы | `intext:"machine learning"` |
| `OR` | Одно условие ИЛИ другое | `Python OR Java` |

### Общая логика построения запроса

```text
ЧТО ИЩЕМ
+
ГДЕ ИЩЕМ
+
КАКОЙ ФОРМАТ
+
ЗА КАКОЙ ПЕРИОД
+
ЧТО ИСКЛЮЧИТЬ
```

Пример структуры:

```text
site:example.org "точная фраза" filetype:pdf after:2025-01-01 -слово
```
