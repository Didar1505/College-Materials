# Строки (str) в Python

Строка (`str`) — это тип данных, который используется для хранения текста. Строка может содержать буквы, цифры, пробелы и специальные символы.

```python
name = "Alex"
city = 'Berlin'
message = "Hello, world!"
number_text = "12345"
```

**Обратите внимание студентам:** `"12345"` — это строка, а `12345` — целое число (`int`). Внешне они похожи, но Python работает с ними по-разному.

```python
a = "10"
b = "20"
print(a + b)           # 1020 — объединение строк
print(int(a) + int(b)) # 30 — сложение чисел
```

Строки можно записывать в одинарных и двойных кавычках. Главное — закрывать их тем же типом кавычек, которым они были открыты.

```python
print("Python")
print('Python')
```

Если внутри строки нужны кавычки, можно использовать разные типы:

```python
print("I'm a student")
print('He said: "Hello!"')
```

---

### Функция `len()`

Функция `len()` возвращает количество символов в строке. Пробелы тоже считаются.

```python
text = "Hello"
print(len(text))  # 5

text = "Hello world"
print(len(text))  # 11
```

**Демонстрация со вводом:**

```python
name = input("Введите имя: ")
print("Количество символов:", len(name))
```

**Вопрос студентам:** что выведет программа?

```python
text = "Python "
print(len(text))
```

*Ответ:* `7`, потому что после слова есть пробел.

# 2. Индексы строк — 15 минут

### Что такое индекс

Индекс — это номер позиции символа в строке. В Python индексация начинается с нуля.

Рассмотрим строку:
```python
text = "PYTHON"
```

Её позиции выглядят так:
* `P` — индекс 0
* `Y` — индекс 1
* `T` — индекс 2
* `H` — индекс 3
* `O` — индекс 4
* `N` — индекс 5

Первый символ имеет индекс 0, последний — индекс 5.

Чтобы получить символ, указываем индекс в квадратных скобках:

```python
text = "PYTHON"
print(text[0])  # P
print(text[1])  # Y
print(text[2])  # T
print(text[5])  # N
```

**Важно:** `text[1]` означает второй символ, а не первый.

---

### Отрицательные индексы

Python позволяет обращаться к символам с конца строки.

```python
text = "PYTHON"
print(text[-1])  # N — последний символ
print(text[-2])  # O — предпоследний
print(text[-3])  # H
```

Покажите студентам, что `text[-1]` удобно использовать, когда нужно получить последний символ и длина строки заранее неизвестна.

```python
word = input("Введите слово: ")
print("Первый символ:", word[0])
print("Последний символ:", word[-1])
```

---

### Ошибка `IndexError`

Что произойдёт, если обратиться к индексу, которого нет?

```python
text = "CAT"
print(text[3])
```

Возникнет `IndexError`: в строке `"CAT"` есть только индексы 0, 1 и 2.

* Чтобы узнать длину строки, используем `len(text)`. Для строки непустой длины последний индекс равен `len(text) - 1`.

```python
text = "CAT"
print(text[len(text) - 1])  # T
print(text[-1])             # T
```

Оба способа возвращают последний символ. Второй обычно короче и понятнее.

---

# 3. Перебор строки с помощью циклов — 15 минут

Строка состоит из символов, поэтому её можно перебирать циклом `for`.

### Способ 1. Перебор символов напрямую

```python
word = "PYTHON"
for char in word:
    print(char)
```

*Результат:*
```text
P
Y
T
H
O
N
```

Переменная `char` на каждой итерации получает очередной символ. Название переменной можно выбрать любое, но важно понимать, что именно в ней хранится.

---

### Способ 2. Перебор через индексы

```python
word = "PYTHON"
for i in range(len(word)):
    print(i, word[i])
```

*Результат:*
```text
0 P
1 Y
2 T
3 H
4 O
5 N
```

Разберём выражение:
* `len(word)` — количество символов.
* `range(len(word))` — последовательность индексов от `0` до `len(word) - 1`.
* `word[i]` — символ по текущему индексу.

**Чем отличаются эти способы?**
* Первый способ удобен, если нужны только символы:
  ```python
  for char in word:
      print(char)
  ```
* Второй — если нужен индекс каждого символа:
  ```python
  for i in range(len(word)):
      print("Индекс:", i, "Символ:", word[i])
  ```

---

### Подсчёт символов по условию

Например, посчитаем, сколько раз в строке встречается буква `a`:

```python
text = "banana"
count = 0
for char in text:
    if char == "a":
        count += 1
print(count)  # 3
```

Здесь объединяются уже знакомые темы: цикл, условие и счётчик.

---

### Подсчёт цифр в строке

```python
text = "room25floor8"
count = 0
for char in text:
    if char >= "0" and char <= "9":
        count += 1
print("Количество цифр:", count)  # 3
```

В этом примере сравнение символов используется для определения цифр. Позже можно изучить более удобный метод `char.isdigit()`.

# 4. Срезы строк — 15 минут

### Что такое срез

Индекс позволяет получить один символ, а срез позволяет получить часть строки.

**Общий синтаксис:**
```python
text[start:stop:step]
```

* `start` — индекс, с которого начинаем.
* `stop` — индекс, на котором останавливаемся, не включая его.
* `step` — шаг, с которым выбираем символы.

Параметры можно пропускать.

---

### Пример 1. Получение части строки

```python
text = "PYTHON"
print(text[0:3])  # PYT
print(text[1:4])  # YTH
print(text[2:5])  # THO
```

**Почему `text[0:3]` возвращает `"PYT"`, а не `"PYTH"`?**
Потому что начальный индекс включается, а конечный не включается. Python берёт символы с индексами 0, 1 и 2.

---

### Пример 2. Пропуск начального или конечного индекса

```python
text = "PYTHON"
print(text[:3])   # PYT
print(text[3:])   # HON
print(text[:])    # PYTHON
```

Если начало не указано, Python начинает с начала строки. Если конец не указан, берёт символы до конца строки.

---

### Пример 3. Срез с шагом

```python
text = "ABCDEFGH"
print(text[::2])   # ACEG
print(text[1::2])  # BDFH
```

В первом случае берётся каждый второй символ, начиная с индекса 0. Во втором — начиная с индекса 1.

---

### Пример 4. Разворот строки

```python
text = "PYTHON"
print(text[::-1])  # NOHTYP
```

Шаг `-1` означает движение с конца строки к началу. Это удобный способ получить строку в обратном порядке. Позже его можно использовать для проверки палиндромов.

---

### Практическая демонстрация

```python
word = input("Введите слово: ")
print("Первые три символа:", word[:3])
print("Последние два символа:", word[-2:])
print("Слово наоборот:", word[::-1])
```

При вводе `COMPUTER` результат будет таким:
```text
Первые три символа: COM
Последние два символа: ER
Слово наоборот: RETUPMOC
```

**Важно:** если строка слишком короткая, срез обычно не вызывает `IndexError`. Например, `"AB"[:3]` вернёт `"AB"`. Это отличается от обращения к отсутствующему символу через индекс.

# 5. Строки нельзя изменять по индексу

Это важный момент, который нужно объяснить до практических заданий.

Строки в Python **неизменяемые**. Это означает, что нельзя заменить отдельный символ непосредственно через индекс.

```python
word = "CAT"
word[0] = "B"  # Ошибка!
```

Python выдаст `TypeError`.

Если нужно получить новое слово, можно создать новую строку:

```python
word = "CAT"
word = "B" + word[1:]
print(word)  # BAT
```

Здесь мы не изменили существующую строку по индексу. Мы создали новую строку `"BAT"` и присвоили её переменной `word`.

Ещё один пример:

```python
word = "python"
word = word.upper()
print(word)  # PYTHON
```

Метод `upper()` возвращает новую строку в верхнем регистре. Само исходное значение строки не меняется.

### Задача 1. Первый и последний символы

**Условие:** пользователь вводит непустое слово. Выведите первый и последний символы.

**Решение:**
```python
word = input("Введите слово: ")
print("Первый символ:", word[0])
print("Последний символ:", word[-1])
```

*Пример:*
```text
Введите слово: Python
Первый символ: P
Последний символ: n
```

**Что объяснить:** индекс `0` обозначает первый символ, а `-1` — последний.

---

### Задача 2. Символы на чётных индексах

**Условие:** пользователь вводит строку. Выведите символы, индексы которых чётные: 0, 2, 4 и так далее.

**Решение через индексы:**
```python
text = input("Введите строку: ")
for i in range(len(text)):
    if i % 2 == 0:
        print(text[i])
```

**Альтернативное решение через срез:**
```python
text = input("Введите строку: ")
print(text[::2])
```

**Что объяснить:** первая версия использует цикл и условие, вторая — срез с шагом 2. Это разные способы решить одну задачу.

### Задача 3. Подсчёт гласных

**Условие:** посчитайте количество русских гласных букв в введённой строке. Считайте `а`, `е`, `ё`, `и`, `о`, `у`, `ы`, `э`, `ю`, `я` и их заглавные варианты.

**Решение:**
```python
text = input("Введите строку: ")
vowels = "аеёиоуыэюяАЕЁИОУЫЭЮЯ"
count = 0
for char in text:
    if char in vowels:
        count += 1
print("Количество гласных:", count)
```

*Пример:*
```text
Введите строку: Привет, мир!
Количество гласных: 3
```

**Что объяснить:** выражение `char in vowels` проверяет, содержится ли символ в строке `vowels`. Счётчик увеличивается только при выполнении условия.

### Задача 4. Проверка первой буквы

**Условие:** пользователь вводит слово. Выведите `Да`, если оно начинается с заглавной буквы, и `Нет` в противном случае. Предполагается, что пользователь вводит непустую строку.

**Решение:**
```python
word = input("Введите слово: ")
if word[0].isupper():
    print("Да")
else:
    print("Нет")
```

*Пример:*
```text
Введите слово: Python
Да
```

**Что объяснить:** `word[0]` получает первый символ, а `isupper()` проверяет, является ли он заглавной буквой.

### Задача 5. Палиндром

**Условие:** палиндром — это слово, которое читается одинаково слева направо и справа налево. Проверьте, является ли введённое слово палиндромом. Регистр букв пока учитывайте: `Казак` и `казак` — разные строки.

**Решение:**
```python
word = input("Введите слово: ")
if word == word[::-1]:
    print("Это палиндром")
else:
    print("Это не палиндром")
```

*Пример:*
```text
Введите слово: level
Это палиндром
```

**Что объяснить:** срез `[::-1]` создаёт строку в обратном порядке. Затем оператор `==` сравнивает исходную и перевёрнутую строки.

### Задача 6. Подсчёт цифр

**Условие:** дана строка, которая может содержать буквы, цифры и другие символы. Подсчитайте количество цифр.

**Решение:**
```python
text = input("Введите строку: ")
count = 0
for char in text:
    if char.isdigit():
        count += 1
print("Количество цифр:", count)
```

*Пример:*
```text
Введите строку: room25floor8
Количество цифр: 3
```

**Что объяснить:** `isdigit()` проверяет, является ли символ цифрой. Переменная `count` хранит количество найденных цифр.

### Задача 8. Подсчёт определённой буквы

**Условие:** пользователь вводит строку и одну букву. Посчитайте, сколько раз эта буква встречается в строке. Сравнение чувствительно к регистру.

**Решение:**
```python
text = input("Введите строку: ")
letter = input("Введите одну букву: ")
count = 0
for char in text:
    if char == letter:
        count += 1
print("Количество вхождений:", count)
```

*Пример:*
```text
Введите строку: banana
Введите одну букву: a
Количество вхождений: 3
```

**Что объяснить:** цикл проходит по всем символам. Каждый раз, когда текущий символ совпадает с введённой буквой, счётчик увеличивается.

### Задача 9. Чередование регистра по индексам

**Условие:** выведите символы строки на чётных индексах в верхнем регистре, а на нечётных — в нижнем. Пробелы также считаются символами и занимают индексы.

**Решение:**
```python
text = input("Введите строку: ")
result = ""
for i in range(len(text)):
    if i % 2 == 0:
        result += text[i].upper()
    else:
        result += text[i].lower()
print(result)
```

*Пример:*
```text
Введите строку: python
PyThOn
```

**Что объяснить:** индекс `i` позволяет определить позицию символа. В зависимости от чётности индекса применяется `upper()` или `lower()`. Здесь переменная `result` постепенно накапливает новую строку.

### Задача 10. Самая длинная последовательность одинаковых символов

**Условие:** дана непустая строка. Найдите максимальное количество одинаковых символов, идущих подряд.  
*Пример:* для `aaabbccccdaa` ответ — `4`, потому что символ `c` повторяется подряд четыре раза.

**Решение:**
```python
text = input("Введите строку: ")
current = 1
maximum = 1
for i in range(1, len(text)):
    if text[i] == text[i - 1]:
        current += 1
    else:
        current = 1
    if current > maximum:
        maximum = current
print("Максимальная последовательность:", maximum)
```

*Пример:*
```text
Введите строку: aaabbccccdaa
Максимальная последовательность: 4
```

**Что объяснить:** цикл начинается с индекса `1`, поскольку мы сравниваем текущий символ с предыдущим. Если они совпадают, увеличиваем длину текущей последовательности. Если нет — начинаем новую последовательность с единицы. Эта задача сложнее предыдущих: она использует индексы, условие, цикл и два счётчика.
