# 2. Что такое методы строк?

**Метод** — это функция, которая принадлежит определённому объекту и вызывается через точку.

В Python строки являются объектами типа `str`, у которых есть множество встроенных методов.

### Синтаксис

```python
строка.метод(аргументы)
```

Например:

```python
text = "hello"

print(text.upper())
```

Результат:

```text
HELLO
```

Здесь:

- `text` — переменная, содержащая строку.
- `.` — оператор обращения к методу.
- `upper` — название метода.
- `()` — круглые скобки для вызова метода.

### Чем метод отличается от функции?

Обычная функция вызывается самостоятельно:

```python
text = "Python"

print(len(text))
```

Метод вызывается через объект:

```python
text = "Python"

print(text.upper())
```

### Важная особенность строк

Строки в Python являются **неизменяемыми** (`immutable`).

Методы строк не изменяют исходную строку, а возвращают результат обработки.

```python
text = "hello"

text.upper()

print(text)  # hello
```

Почему строка осталась прежней?

Потому что результат метода не был сохранён.

Правильный вариант:

```python
text = "hello"

text = text.upper()

print(text)  # HELLO
```

**Объяснение:** метод возвращает новую строку, которую мы можем присвоить переменной.

# 3. Методы изменения регистра

Регистр — это написание букв в верхнем или нижнем виде.

Например:

- `python` — нижний регистр.
- `PYTHON` — верхний регистр.
- `Python` — первая буква заглавная.

## 3.1. Метод `upper()`

Преобразует все буквы строки в верхний регистр.

```python
text = "hello python"

print(text.upper())
```

Результат:

```text
HELLO PYTHON
```

**Где применяется?**

Например, когда нужно привести данные к единому регистру перед сравнением.

```python
answer = input("Введите YES или NO: ")

if answer.upper() == "YES":
    print("Вы согласились")
else:
    print("Другой ответ")
```

Программа примет `yes`, `Yes`, `YES` и другие варианты регистра.

## 3.2. Метод `lower()`

Преобразует буквы в нижний регистр.

```python
text = "HELLO WORLD"

print(text.lower())
```

Результат:

```text
hello world
```

### Демонстрационная задача: проверка пароля

Для учебного примера проверим условный код доступа без учёта регистра.

```python
secret = "python123"

password = input("Введите код доступа: ")

if password.lower() == secret:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")
```

**Важно:** настоящие пароли обычно чувствительны к регистру. Такой способ сравнения подходит только для учебного кода доступа, а не для реальной авторизации.

## 3.3. Метод `capitalize()`

Преобразует первую букву строки в верхний регистр, а остальные буквы — в нижний.

```python
text = "hELLO WORLD"

print(text.capitalize())
```

Результат:

```text
Hello world
```

## 3.4. Метод `title()`

Преобразует начало каждого слова в верхний регистр.

```python
text = "hello python world"

print(text.title())
```

Результат:

```text
Hello Python World
```

Метод удобен для простого форматирования заголовков, но не всегда корректно обрабатывает настоящие имена и фамилии.

## 3.5. Метод `swapcase()`

Меняет регистр каждой буквы на противоположный.

```python
text = "Hello PYTHON"

print(text.swapcase())
```

Результат:

```text
hELLO python
```

### Практическая демонстрация

Пользователь вводит имя и фамилию в произвольном регистре. Необходимо привести их к единому формату.

```python
full_name = input("Введите имя и фамилию: ")

result = full_name.title()

print("Результат:", result)
```

Пример:

```text
Введите имя и фамилию: иВАН иВАНОВ
Результат: Иван Иванов
```

### Задание студентам

Программа должна вывести:

2. Название полностью строчными буквами.
3. Название с первой заглавной буквой.

# 4. Удаление пробелов и замена текста

При вводе данных пользователи часто добавляют лишние пробелы.

Например:

```python
name = "   Александр   "
```

Если сравнить эту строку с `"Александр"`, результат будет `False`.

Для обработки таких ситуаций существуют специальные методы.

## 4.1. Метод `strip()`

Удаляет пробельные символы в начале и конце строки.

```python
text = "   Hello World   "

print(text.strip())
```

Результат:

```text
Hello World
```

Обратите внимание: пробел между словами остаётся.

Метод удаляет пробелы только по краям строки.

### Пример с пользовательским вводом

```python
username = input("Введите логин: ")

username = username.strip()

print("Ваш логин:", username)
```

## 4.2. Методы `lstrip()` и `rstrip()`

`lstrip()` удаляет пробельные символы слева.

`rstrip()` удаляет пробельные символы справа.

```python
text = "   Python   "

print(repr(text.lstrip()))
print(repr(text.rstrip()))
```

Результат:

```text
'Python   '
'   Python'
```

Здесь `repr()` используется для того, чтобы пробелы были заметны при выводе.

### Дополнительная возможность `strip()`

Можно указать символы, которые необходимо удалить по краям строки.

```python
text = "***Python***"

print(text.strip("*"))
```

Результат:

```text
Python
```

Важно: аргумент `strip()` — это набор удаляемых символов, а не подстрока, которую нужно найти целиком.

## 4.3. Метод `replace()`

Используется для замены одной подстроки другой.

Синтаксис:

```python
text.replace(old, new)
```

Пример:

```python
text = "I like Java"

result = text.replace("Java", "Python")

print(result)
```

Результат:

```text
I like Python
```

### Замена всех вхождений

```python
text = "apple apple banana apple"

print(text.replace("apple", "orange"))
```

Результат:

```text
orange orange banana orange
```

### Замена с ограничением

Третий аргумент позволяет указать максимальное количество замен.

```python
text = "cat cat cat"

print(text.replace("cat", "dog", 2))
```

Результат:

```text
dog dog cat
```

### Демонстрационная задача: исправление текста

Пользователь вводит предложение, в котором слово `Java` необходимо заменить на `Python`.

```python
text = input("Введите предложение: ")

text = text.replace("Java", "Python")

print("Исправленный текст:", text)
```

### Задание студентам

Дана строка:

```python
text = "2026-10-16"
```

Используя `replace()`, преобразуйте её в формат:

```text
2026/10/16
```

# 5. Методы поиска и подсчёта

Ранее мы использовали оператор `in` для проверки наличия символа или подстроки.

```python
text = "Hello Python"

print("Python" in text)  # True
```

Однако иногда нам необходимо не просто узнать, присутствует ли подстрока, но и определить её позицию или количество вхождений.

## 5.1. Метод `find()`

Находит первое вхождение подстроки и возвращает его начальный индекс.

```python
text = "Hello Python"

print(text.find("Python"))
```

Результат:

```text
6
```

Если подстрока не найдена, метод возвращает `-1`.

```python
text = "Hello Python"

print(text.find("Java"))  # -1
```

### Поиск с определённой позиции

```python
text = "banana"

print(text.find("a", 2))
```

Результат:

```text
3
```

Поиск начинается с индекса `2`.

## 5.2. Метод `rfind()`

Находит последнее вхождение подстроки.

```python
text = "banana"

print(text.find("a"))   # 1
print(text.rfind("a"))  # 5
```

Разница:

- `find()` возвращает индекс первого вхождения.
- `rfind()` возвращает индекс последнего вхождения.

## 5.3. Метод `count()`

Возвращает количество неперекрывающихся вхождений подстроки.

```python
text = "banana"

print(text.count("a"))  # 3
```

Ещё один пример:

```python
text = "Python Java Python C++ Python"

print(text.count("Python"))
```

Результат:

```text
3
```

### Сравнение с циклом

Раньше мы считали символы следующим образом:

```python
text = "banana"
counter = 0

for char in text:
    if char == "a":
        counter += 1

print(counter)
```

Теперь:

```python
text = "banana"

print(text.count("a"))
```

**Вывод:** встроенные методы позволяют выполнять типовые операции без написания дополнительных циклов.

### Демонстрационная задача: поиск слова

Пользователь вводит предложение и искомое слово.

Программа должна определить, сколько раз указанная подстрока встречается в предложении без учёта регистра.

```python
text = input("Введите предложение: ")
word = input("Введите слово: ")

text = text.lower()
word = word.lower()

print("Количество вхождений:", text.count(word))
```

**Примечание:** `count()` ищет подстроки, а не обязательно отдельные слова. Например, поиск `"кот"` найдёт совпадение и внутри `"котик"`.

# 6. Методы проверки содержимого строки

Некоторые методы возвращают логическое значение `True` или `False`.

Это позволяет использовать их внутри условий `if`.

## 6.1. Метод `isalpha()`

Проверяет, состоит ли непустая строка только из букв.

```python
print("Python".isalpha())   # True
print("Python123".isalpha()) # False
print("Hello World".isalpha()) # False
```

Пробел не является буквой.

### Пример: проверка имени

```python
name = input("Введите имя: ")

if name.isalpha():
    print("Имя содержит только буквы")
else:
    print("Некорректный ввод")
```

Это упрощённая учебная проверка: реальные имена могут содержать дефисы, пробелы и другие символы.

## 6.2. Метод `isdigit()`

Проверяет, состоит ли непустая строка из цифровых символов.

```python
print("12345".isdigit())  # True
print("12a45".isdigit())  # False
print("-123".isdigit())   # False
```

### Пример: проверка возраста

```python
age = input("Введите возраст: ")

if age.isdigit():
    print("Возраст:", int(age))
else:
    print("Ошибка: введите число")
```

Здесь мы сначала проверяем данные, а затем преобразуем строку в `int`.

Метод `isdigit()` не является универсальной проверкой любого числа: отрицательные и дробные числа он не распознаёт как целые строки с цифрами.

## 6.3. Метод `isalnum()`

Проверяет, состоит ли непустая строка только из букв и цифр.

```python
print("Python123".isalnum())  # True
print("Python_123".isalnum()) # False
print("Hello World".isalnum()) # False
```

Метод может использоваться при простой проверке логинов.

```python
username = input("Введите логин: ")

if username.isalnum():
    print("Логин принят")
else:
    print("Допускаются только буквы и цифры")
```

## 6.4. Метод `isspace()`

Проверяет, состоит ли непустая строка только из пробельных символов.

```python
print("   ".isspace())  # True
print(" \t ".isspace()) # True
print(" a ".isspace())  # False
```

## 6.5. Методы `startswith()` и `endswith()`

Проверяют, начинается или заканчивается строка указанной подстрокой.

```python
text = "Python programming"

print(text.startswith("Python"))  # True
print(text.endswith("Java"))      # False
```

### Пример: проверка расширения файла

```python
filename = input("Введите имя файла: ")

filename = filename.lower()

if filename.endswith(".jpg") or filename.endswith(".png"):
    print("Это изображение")
else:
    print("Другой тип файла")
```

Метод `endswith()` также поддерживает кортеж окончаний:

```python
filename = "photo.PNG"

if filename.lower().endswith((".jpg", ".png")):
    print("Это изображение")
```

**Важно:** расширение файла не гарантирует, что внутри действительно находится изображение.

### Задание студентам

Пользователь вводит название файла.

Программа должна определить:

- `.py` — файл Python.
- `.txt` — текстовый файл.
- `.jpg` или `.png` — изображение.
- Любое другое расширение — неизвестный тип файла.

Используйте `if`, `elif`, `else` и `endswith()`.

# 7. Разделение и объединение строк

Иногда текст содержит несколько отдельных значений.

Например:

```python
data = "Иван,20,Москва"
```

Нам необходимо получить имя, возраст и город по отдельности.

## 7.1. Метод `split()`

Разделяет строку на части и возвращает список (`list`).

```python
text = "Python Java C++"

words = text.split()

print(words)
```

Результат:

```text
['Python', 'Java', 'C++']
```

**Объяснение:** метод `split()` без аргументов разделяет строку по пробельным символам.

### Разделение по указанному символу

```python
data = "Иван,20,Москва"

result = data.split(",")

print(result)
```

Результат:

```text
['Иван', '20', 'Москва']
```

### Обращение к отдельным элементам

```python
data = "Иван,20,Москва"

parts = data.split(",")

print("Имя:", parts[0])
print("Возраст:", parts[1])
print("Город:", parts[2])
```

Результат:

```text
Имя: Иван
Возраст: 20
Город: Москва
```

### Демонстрационная задача: подсчёт слов

```python
text = input("Введите предложение: ")

words = text.split()

print("Количество слов:", len(words))
```

Пример:

```text
Введите предложение: Я изучаю язык Python
Количество слов: 4
```

Это простой подсчёт частей текста, разделённых пробельными символами.

## 7.2. Метод `join()`

Объединяет несколько строк в одну с помощью указанного разделителя.

Синтаксис:

```python
"разделитель".join(список)
```

Пример:

```python
words = ["Python", "Java", "C++"]

result = ", ".join(words)

print(result)
```

Результат:

```text
Python, Java, C++
```

### Объединение через дефис

```python
words = ["2026", "10", "16"]

result = "-".join(words)

print(result)
```

Результат:

```text
2026-10-16
```

### Совместное использование `split()` и `join()`

```python
text = "Python is very interesting"

words = text.split()

result = "-".join(words)

print(result)
```

Результат:

```text
Python-is-very-interesting
```

### Демонстрационная задача: удаление лишних пробелов

```python
text = "Python    is    awesome"

words = text.split()

result = " ".join(words)

print(result)
```

Результат:

```text
Python is awesome
```

**Объяснение:**

1. `split()` разделяет строку на слова, игнорируя повторяющиеся пробельные разделители.
2. `join()` объединяет слова, вставляя между ними ровно один пробел.

# 8. Комбинирование нескольких методов

Методы можно вызывать последовательно, если результат предыдущего метода поддерживает следующий.

Например:

```python
text = "   HELLO PYTHON   "

result = text.strip().lower().replace("python", "world")

print(result)
```

Результат:

```text
hello world
```

Разберём выполнение по шагам.

**Шаг 1. Удаление пробелов**

```python
text.strip()
```

Результат:

```text
HELLO PYTHON
```

**Шаг 2. Преобразование в нижний регистр**

```python
text.strip().lower()
```

Результат:

```text
hello python
```

**Шаг 3. Замена слова**

```python
text.strip().lower().replace("python", "world")
```

Результат:

```text
hello world
```

### Пример из реальной задачи: нормализация логина

```python
username = input("Введите логин: ")

username = username.strip().lower()

if username.isalnum():
    print("Логин принят:", username)
else:
    print("Недопустимые символы")
```

# 12. Справочник методов строк

| Метод | Назначение |
|---|---|
| `upper()` | Преобразует буквы в верхний регистр |
| `lower()` | Преобразует буквы в нижний регистр |
| `capitalize()` | Делает первую букву заглавной, остальные строчными |
| `title()` | Преобразует начало каждого слова в верхний регистр |
| `swapcase()` | Меняет регистр букв на противоположный |
| `strip()` | Удаляет символы по краям строки |
| `lstrip()` | Удаляет символы слева |
| `rstrip()` | Удаляет символы справа |
| `replace()` | Заменяет подстроку |
| `find()` | Находит первое вхождение подстроки |
| `rfind()` | Находит последнее вхождение подстроки |
| `count()` | Подсчитывает вхождения подстроки |
| `isalpha()` | Проверяет, состоит ли строка из букв |
| `isdigit()` | Проверяет, состоит ли строка из цифровых символов |
| `isalnum()` | Проверяет, состоит ли строка из букв и цифр |
| `isspace()` | Проверяет наличие только пробельных символов |
| `startswith()` | Проверяет начало строки |
| `endswith()` | Проверяет конец строки |
| `split()` | Разделяет строку на список |
| `join()` | Объединяет строки с разделителем |
