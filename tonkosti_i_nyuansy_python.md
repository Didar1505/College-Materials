# Тонкости и нюансы языка Python

Python считается одним из самых простых языков программирования, но у него есть множество особенностей, которые могут удивить даже опытных разработчиков.

В этом материале разберём **25 интересных нюансов Python 3**: от переменных, строк и списков до особенностей функций, циклов и объектов. Каждый пункт содержит пример кода и объяснение.

## 1. Переменные хранят ссылки на объекты

В Python переменная — это имя, связанное с объектом. Особенно важно это при работе со списками.

```python
a = [1, 2, 3]
b = a

b.append(4)

print(a)
print(b)
```

**Результат:**

```text
[1, 2, 3, 4]
[1, 2, 3, 4]
```

**Почему?** Обе переменные ссылаются на один список. Изменение через `b` отражается и в `a`.

Чтобы создать отдельный список:

```python
a = [1, 2, 3]
b = a.copy()

b.append(4)

print(a)  # [1, 2, 3]
print(b)  # [1, 2, 3, 4]
```

> **Нюанс:** `copy()` создаёт поверхностную копию. Для вложенных изменяемых объектов может понадобиться `copy.deepcopy()`.

## 2. Операторы `==` и `is` — не одно и то же

- `==` сравнивает значения объектов.
- `is` проверяет, являются ли они одним объектом.

```python
a = [1, 2, 3]
b = [1, 2, 3]

print(a == b)  # True
print(a is b)  # False
```

Списки содержат одинаковые элементы, но являются разными объектами.

При проверке на `None` принято использовать `is`:

```python
value = None

if value is None:
    print("Значение отсутствует")
```

## 3. Не все пустые значения одинаковы

Python воспринимает следующие значения как ложные:

```python
False
None
0
0.0
""
[]
{}
set()
```

Например:

```python
name = ""

if not name:
    print("Имя не указано")
```

Но есть неожиданный момент:

```python
print(bool("False"))  # True
print(bool("0"))      # True
print(bool(" "))      # True
```

Любая непустая строка считается истинной, даже если в ней написано `"False"`.

## 4. `True` и `False` связаны с числами

В Python тип `bool` является подклассом `int`.

```python
print(True == 1)   # True
print(False == 0)  # True

print(True + True)  # 2
print(10 + True)   # 11
```

Это позволяет подсчитывать количество выполненных условий:

```python
numbers = [10, -5, 7, -2, 0]

count = sum(x > 0 for x in numbers)

print(count)  # 2
```

## 5. Почему `0.1 + 0.2` не равно `0.3`?

```python
print(0.1 + 0.2)
```

**Результат:**

```text
0.30000000000000004
```

Это связано с представлением чисел с плавающей точкой в двоичной системе.

```python
print(0.1 + 0.2 == 0.3)  # False
```

Лучше сравнивать с допустимой погрешностью:

```python
import math

print(math.isclose(0.1 + 0.2, 0.3))  # True
```

Для финансовых расчётов, требующих точной десятичной арифметики, часто используют `decimal.Decimal`.

## 6. Деление и округление отрицательных чисел

В Python существует два варианта деления:

```python
print(7 / 2)   # 3.5
print(7 // 2)  # 3
```

Но с отрицательными числами появляется нюанс:

```python
print(-7 // 2)  # -4
```

Почему не `-3`? Потому что `//` округляет результат вниз, в сторону отрицательной бесконечности.

Остаток тоже может удивить:

```python
print(-7 % 3)  # 2
```

Для целых чисел выполняется связь:

```text
a = (a // b) * b + (a % b)
```

## 7. Строки в Python неизменяемы

```python
name = "Python"

name[0] = "J"  # TypeError
```

Нельзя изменить отдельный символ существующей строки. Можно создать новую:

```python
name = "Python"
name = "J" + name[1:]

print(name)  # Jython
```

Методы строк обычно возвращают новую строку:

```python
text = "hello"
text.upper()

print(text)  # hello
```

Чтобы сохранить результат:

```python
text = text.upper()

print(text)  # HELLO
```

## 8. Срезы позволяют использовать отрицательные индексы

```python
numbers = [10, 20, 30, 40, 50]

print(numbers[-1])    # 50
print(numbers[-2])    # 40
print(numbers[1:4])   # [20, 30, 40]
print(numbers[::-1])  # [50, 40, 30, 20, 10]
```

Особенно интересно:

```python
text = "Python"

print(text[::-1])  # nohtyP
```

Шаг `-1` позволяет получить строку в обратном порядке.

## 9. Умножение списков может вести себя неожиданно

Попробуем создать двумерный список:

```python
matrix = [[0] * 3] * 3

matrix[0][0] = 9

print(matrix)
```

**Результат:**

```text
[[9, 0, 0],
 [9, 0, 0],
 [9, 0, 0]]
```

Почему изменились все строки? Потому что каждая строка ссылается на один и тот же внутренний список.

Правильное создание:

```python
matrix = [[0] * 3 for _ in range(3)]

matrix[0][0] = 9

print(matrix)
```

**Результат:**

```text
[[9, 0, 0],
 [0, 0, 0],
 [0, 0, 0]]
```

## 10. Метод `sort()` ничего не возвращает

```python
numbers = [5, 2, 8, 1]

result = numbers.sort()

print(numbers)  # [1, 2, 5, 8]
print(result)   # None
```

Метод `sort()` изменяет исходный список. Функция `sorted()` создаёт новый:

```python
numbers = [5, 2, 8, 1]

result = sorted(numbers)

print(numbers)  # [5, 2, 8, 1]
print(result)   # [1, 2, 5, 8]
```

## 11. Не изменяйте список во время перебора без необходимости

```python
numbers = [1, 2, 3, 4, 5, 6]

for number in numbers:
    if number % 2 == 0:
        numbers.remove(number)

print(numbers)
```

В этом конкретном случае получится правильный результат, но такой способ ненадёжен: при удалении элементы смещаются, и цикл может пропускать некоторые из них.

Безопаснее создать новый список:

```python
numbers = [1, 2, 3, 4, 5, 6]

numbers = [x for x in numbers if x % 2 != 0]

print(numbers)  # [1, 3, 5]
```

## 12. `and` и `or` возвращают не только `True` или `False`

Логические операторы могут возвращать сами операнды.

```python
print(0 or 100)          # 100
print("" or "Без имени") # Без имени
print(5 and 10)          # 10
print(0 and 10)          # 0
```

Это иногда применяют для значений по умолчанию:

```python
username = ""
display_name = username or "Гость"

print(display_name)  # Гость
```

**Важно:** если `0` или `False` — допустимые значения, конструкция `or` может случайно их заменить.

## 13. Функции могут запоминать изменяемые аргументы

Одна из известных ловушек Python:

```python
def add_number(number, numbers=[]):
    numbers.append(number)
    return numbers

print(add_number(1))
print(add_number(2))
print(add_number(3))
```

**Результат:**

```text
[1]
[1, 2]
[1, 2, 3]
```

Значение аргумента по умолчанию создаётся один раз — при определении функции.

Правильный способ:

```python
def add_number(number, numbers=None):
    if numbers is None:
        numbers = []

    numbers.append(number)
    return numbers
```

Теперь каждый вызов без второго аргумента будет создавать отдельный список.

## 14. В Python можно возвращать несколько значений

```python
def calculate(a, b):
    return a + b, a * b

summa, product = calculate(5, 3)

print(summa)    # 8
print(product)  # 15
```

Технически функция возвращает один кортеж:

```python
result = calculate(5, 3)

print(result)        # (8, 15)
print(type(result))  # <class 'tuple'>
```

Запись `summa, product = ...` выполняет распаковку.

## 15. Можно обменять значения переменных без третьей переменной

```python
a = 10
b = 20

a, b = b, a

print(a)  # 20
print(b)  # 10
```

Это работает благодаря упаковке и распаковке значений.

## 16. Циклы `for` и `while` могут иметь `else`

```python
for number in range(5):
    print(number)
else:
    print("Цикл завершён")
```

Блок `else` выполняется, если цикл завершился без `break`.

Пример поиска:

```python
numbers = [2, 4, 6, 8]

for number in numbers:
    if number == 5:
        print("Найдено")
        break
else:
    print("Число не найдено")
```

**Результат:**

```text
Число не найдено
```

## 17. `range()` не создаёт обычный список

```python
numbers = range(1, 1000000)

print(type(numbers))
```

**Результат:**

```text
<class 'range'>
```

`range()` хранит параметры последовательности, а не миллион отдельных целых чисел в списке.

При необходимости:

```python
numbers = list(range(1, 6))

print(numbers)  # [1, 2, 3, 4, 5]
```

**Нюанс:** конечная граница диапазона не включается.

## 18. Множества автоматически удаляют дубликаты

```python
numbers = [1, 2, 2, 3, 3, 3, 4]

unique = set(numbers)

print(unique)
```

Множество будет содержать числа `1`, `2`, `3`, `4`, но порядок элементов не гарантируется.

Ещё одна особенность:

```python
data = {1, True, 1.0}

print(len(data))  # 1
```

Поскольку `1 == True == 1.0` и у них одинаковые хеши, множество считает их одним элементом.

## 19. Пустые фигурные скобки создают словарь, а не множество

```python
a = {}

print(type(a))  # <class 'dict'>
```

Чтобы создать пустое множество:

```python
a = set()

print(type(a))  # <class 'set'>
```

## 20. Словари могут содержать не только строковые ключи

```python
students = {
    101: "Али",
    102: "Мария",
    103: "Иван"
}

print(students[101])  # Али
```

Ключами могут быть числа, строки, кортежи и другие хешируемые объекты.

А список в качестве ключа использовать нельзя:

```python
data = {
    [1, 2]: "Значение"
}
```

Это вызовет `TypeError`, потому что список изменяем и не является хешируемым.

## 21. Функция `zip()` останавливается на самой короткой последовательности

```python
names = ["Анна", "Иван", "Мария"]
ages = [18, 20]

for name, age in zip(names, ages):
    print(name, age)
```

**Результат:**

```text
Анна 18
Иван 20
```

Мария не появится, поскольку для неё нет соответствующего возраста.

Если длины должны совпадать:

```python
for name, age in zip(names, ages, strict=True):
    print(name, age)
```

В Python 3.10+ это вызовет `ValueError`, если длины последовательностей различаются.

## 22. Переменная цикла продолжает существовать после цикла

```python
for i in range(5):
    pass

print(i)  # 4
```

В Python обычный цикл `for` не создаёт отдельную локальную область видимости.

## 23. Генераторы можно исчерпать

```python
numbers = (x * 2 for x in range(3))

print(list(numbers))
print(list(numbers))
```

**Результат:**

```text
[0, 2, 4]
[]
```

Генератор выдаёт значения по мере перебора. Когда все значения получены, повторный проход по этому же генератору ничего не возвращает.

Для нового прохода нужно создать новый генератор.

## 24. Lambda-функции внутри цикла могут работать неожиданно

```python
functions = []

for i in range(3):
    functions.append(lambda: i)

for func in functions:
    print(func())
```

**Результат:**

```text
2
2
2
```

Все функции обращаются к одной и той же переменной `i`, которая после цикла равна `2`.

Чтобы сохранить значение на каждой итерации:

```python
functions = []

for i in range(3):
    functions.append(lambda i=i: i)

for func in functions:
    print(func())
```

**Результат:**

```text
0
1
2
```

## 25. Аннотации типов не делают Python строго типизированным

```python
def greet(name: str) -> str:
    return "Привет, " + name
```

В функции указаны типы аргумента и результата. Но Python самостоятельно не проверяет соответствие аннотациям во время обычного вызова.

```python
def double(number: int) -> int:
    return number * 2

print(double("Hi"))  # HiHi
```

Код выполнится, несмотря на аннотацию `int`.

Аннотации помогают IDE, статическим анализаторам (например, mypy и pyright) и другим разработчикам понимать код.

# Проверь себя: 5 неочевидных примеров

Сначала попробуйте определить результат **без запуска** программы, а затем проверьте себя.

### Задача 1

```python
a = [1, 2]
b = a
b += [3]
print(a)
```

**Варианты:**

- А. `[1, 2]`
- Б. `[1, 2, 3]`
- В. Ошибка

### Задача 2

```python
print(bool('0'))
```

**Варианты:**

- А. `True`
- Б. `False`
- В. Ошибка

### Задача 3

```python
print(10 // 3)
print(10 % 3)
```

**Варианты:**

- А. `3` и `1`
- Б. `3.33` и `1`
- В. `3` и `0`

### Задача 4

```python
x = [10, 20, 30]
print(x[-2])
```

**Варианты:**

- А. `10`
- Б. `20`
- В. `30`

### Задача 5

```python
print(list(range(2, 8, 2)))
```

**Варианты:**

- А. `[2, 4, 6, 8]`
- Б. `[2, 4, 6]`
- В. `[2, 3, 4, 5, 6, 7]`

## Ответы и объяснения

1. **Б — `[1, 2, 3]`.** Для списка `+=` изменяет сам объект; обе переменные ссылаются на него.
2. **А — `True`.** Строка `'0'` непустая, поэтому она истинна.
3. **А — `3` и `1`.** `//` даёт целочисленное частное с округлением вниз, `%` — остаток.
4. **Б — `20`.** Индекс `-1` указывает на последний элемент, а `-2` — на предпоследний.
5. **Б — `[2, 4, 6]`.** Шаг равен `2`, а верхняя граница `8` не включается.
