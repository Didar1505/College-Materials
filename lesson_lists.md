# Часть 1. Теоретический материал

## 1. Что такое список и зачем он нужен?

Представим, что нам необходимо написать программу, которая хранит оценки студентов.

Если у нас три оценки, мы можем создать три переменные:

```python
grade1 = 5
grade2 = 4
grade3 = 3
```

Но что делать, если студентов 100?

Создавать 100 отдельных переменных неудобно. Более того, если потребуется найти среднюю оценку, максимальную оценку или вывести все оценки, программа станет слишком большой.

Для решения подобных задач в Python существуют **списки**.

**Список (`list`)** — это встроенный тип данных Python, который позволяет хранить несколько элементов в одной переменной.

```python
grades = [5, 4, 3, 5, 4]
```

Теперь вместо пяти переменных мы используем одну переменную `grades`.

Список можно представить как последовательность ячеек, каждая из которых содержит определённое значение:

| Индекс | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| Значение | 5 | 4 | 3 | 5 | 4 |

Каждый элемент имеет собственный индекс, начиная с нуля.

### Где используются списки?

- Интернет-магазин — список товаров и цен.
- Электронный журнал — список оценок студентов.
- Компьютерная игра — список игроков, инвентаря или очков.
- Музыкальное приложение — список песен.
- Банковская программа — список операций.
- Система регистрации — список пользователей.

Например, список товаров интернет-магазина:

```python
products = ["Ноутбук", "Мышь", "Клавиатура"]
```

Список цен:

```python
prices = [50000, 1500, 3500]
```

Список имён студентов:

```python
students = ["Алексей", "Мария", "Иван"]
```

### Основные особенности списков

| Свойство | Объяснение |
|---|---|
| Упорядоченность | Элементы сохраняют свой порядок |
| Индексация | Каждый элемент имеет индекс |
| Изменяемость | Элементы можно заменять, добавлять и удалять |
| Повторения | Одинаковые значения могут встречаться несколько раз |
| Разные типы данных | В одном списке могут храниться числа, строки и другие объекты |
| Динамический размер | Количество элементов может изменяться во время выполнения программы |

## 2. Создание списков

Для создания списка используются квадратные скобки `[]`.

### Список чисел

```python
numbers = [10, 20, 30, 40, 50]
```

### Список строк

```python
cities = ["Москва", "Казань", "Сочи"]
```

### Список логических значений

```python
answers = [True, False, True, True]
```

### Список с разными типами данных

```python
student = ["Иван", 18, 4.5, True]
```

Python позволяет хранить разные типы данных в одном списке. Однако на практике часто удобнее использовать списки с однотипными элементами.

### Пустой список

```python
numbers = []
```

Пустой список полезен, когда элементы будут добавляться позже:

```python
numbers = []

numbers.append(10)
numbers.append(20)

print(numbers)
```

Результат:

```text
[10, 20]
```

### Создание списка с помощью `list()`

```python
numbers = list(range(1, 6))
print(numbers)
```

Результат:

```text
[1, 2, 3, 4, 5]
```

Здесь `range(1, 6)` задаёт последовательность чисел, а `list()` создаёт из неё список.

Ещё один пример:

```python
letters = list("Python")
print(letters)
```

Результат:

```text
['P', 'y', 't', 'h', 'o', 'n']
```

## 3. Индексы списка

Каждый элемент списка имеет порядковый номер, который называется **индексом**. В Python индексация начинается с нуля, а не с единицы.

```python
fruits = ["Apple", "Banana", "Cherry", "Orange", "Mango"]
```

| Элемент | Apple | Banana | Cherry | Orange | Mango |
|---|---|---|---|---|---|
| Положительный индекс | 0 | 1 | 2 | 3 | 4 |
| Отрицательный индекс | -5 | -4 | -3 | -2 | -1 |

### Обращение к элементу по индексу

```python
fruits = ["Apple", "Banana", "Cherry", "Orange"]

print(fruits[0])
print(fruits[1])
print(fruits[3])
```

Результат:

```text
Apple
Banana
Orange
```

Чтобы получить первый элемент, используется индекс `0`, второй — `1`, третий — `2`.

### Отрицательные индексы

В Python можно обращаться к элементам с конца списка:

```python
fruits = ["Apple", "Banana", "Cherry", "Orange"]

print(fruits[-1])  # Orange
print(fruits[-2])  # Cherry
print(fruits[-3])  # Banana
```

Отрицательная индексация особенно полезна, когда необходимо получить последний элемент, но заранее неизвестно количество элементов.

### Ошибка выхода за пределы списка

```python
numbers = [10, 20, 30]
print(numbers[5])
```

Программа выдаст ошибку:

```text
IndexError: list index out of range
```

Почему? Потому что список содержит только три элемента с индексами `0`, `1`, `2`.

**Объяснение для студентов:** индекс — это адрес элемента внутри списка. Если мы обращаемся к адресу, которого не существует, Python не может найти соответствующий элемент.

## 4. Получение части списка — срезы

Иногда необходимо получить не один элемент, а несколько подряд. Для этого используются **срезы (slicing)**.

Синтаксис:

```python
list[start:stop:step]
```

Где:

- `start` — индекс, с которого начинается срез.
- `stop` — индекс, перед которым заканчивается срез (не включается).
- `step` — шаг, с которым выбираются элементы.

Рассмотрим список:

```python
numbers = [10, 20, 30, 40, 50, 60]
```

### Пример 1. Элементы с индекса 1 по индекс 3

```python
print(numbers[1:4])
```

Результат:

```text
[20, 30, 40]
```

Индекс `4` не включается.

| Индекс | 0 | **1** | **2** | **3** | 4 | 5 |
|---|---|---|---|---|---|---|
| Значение | 10 | **20** | **30** | **40** | 50 | 60 |

### Пример 2. Первые три элемента

```python
print(numbers[:3])
```

Результат:

```text
[10, 20, 30]
```

Если `start` не указан, Python начинает с начала списка.

### Пример 3. Все элементы с индекса 3

```python
print(numbers[3:])
```

Результат:

```text
[40, 50, 60]
```

Если `stop` не указан, Python выбирает элементы до конца.

### Пример 4. Каждый второй элемент

```python
print(numbers[::2])
```

Результат:

```text
[10, 30, 50]
```

### Пример 5. Список в обратном порядке

```python
print(numbers[::-1])
```

Результат:

```text
[60, 50, 40, 30, 20, 10]
```

**Важно:** срез создаёт новый список. Исходный список при этом не изменяется.

## 5. Изменение элементов списка

Одно из важных свойств списков — **изменяемость**. Мы можем изменить любой существующий элемент по индексу.

```python
fruits = ["Apple", "Banana", "Cherry"]
fruits[1] = "Orange"
print(fruits)
```

Результат:

```text
['Apple', 'Orange', 'Cherry']
```

Другой пример:

```python
grades = [5, 4, 3, 4]
grades[2] = 5
print(grades)
```

Результат:

```text
[5, 4, 5, 4]
```

Мы исправили третью оценку с `3` на `5`.

### Изменение нескольких элементов

Можно заменить несколько элементов через срез:

```python
numbers = [10, 20, 30, 40, 50]
numbers[1:3] = [100, 200]
print(numbers)
```

Результат:

```text
[10, 100, 200, 40, 50]
```

### Изменение элементов с помощью цикла

Допустим, требуется увеличить каждое число списка в два раза.

```python
numbers = [2, 4, 6, 8]

for i in range(len(numbers)):
    numbers[i] = numbers[i] * 2

print(numbers)
```

Результат:

```text
[4, 8, 12, 16]
```

Объяснение:

1. `len(numbers)` определяет количество элементов.
2. `range(len(numbers))` создаёт последовательность индексов.
3. `numbers[i]` обращается к элементу по текущему индексу.
4. Новое значение записывается на место старого.

## 6. Добавление элементов в список

Списки могут увеличиваться во время выполнения программы. Для этого используются методы `append()`, `insert()` и `extend()`.

### 6.1. Метод `append()`

Добавляет **один элемент** в конец списка.

```python
numbers = [10, 20, 30]
numbers.append(40)
print(numbers)
```

Результат:

```text
[10, 20, 30, 40]
```

Ещё один пример:

```python
students = []
students.append("Иван")
students.append("Мария")
students.append("Алексей")
print(students)
```

Результат:

```text
['Иван', 'Мария', 'Алексей']
```

Этот метод особенно полезен при создании списка из пользовательского ввода:

```python
numbers = []

for i in range(5):
    number = int(input("Введите число: "))
    numbers.append(number)

print(numbers)
```

### 6.2. Метод `insert()`

Позволяет вставить элемент на определённую позицию.

Синтаксис:

```python
list.insert(index, value)
```

Пример:

```python
numbers = [10, 20, 30]
numbers.insert(1, 15)
print(numbers)
```

Результат:

```text
[10, 15, 20, 30]
```

Число `15` вставлено на индекс `1`, а остальные элементы сдвинулись вправо.

### 6.3. Метод `extend()`

Позволяет добавить несколько элементов из другого итерируемого объекта, например списка.

```python
numbers = [10, 20]
numbers.extend([30, 40, 50])
print(numbers)
```

Результат:

```text
[10, 20, 30, 40, 50]
```

### Отличие `append()` от `extend()`

```python
a = [1, 2]
a.append([3, 4])
print(a)
# [1, 2, [3, 4]]
```

```python
b = [1, 2]
b.extend([3, 4])
print(b)
# [1, 2, 3, 4]
```

В первом случае весь список `[3, 4]` добавляется как один элемент. Во втором добавляются отдельно `3` и `4`.

## 7. Удаление элементов

Для удаления элементов существуют несколько способов.

### 7.1. Метод `remove()`

Удаляет первое вхождение указанного значения.

```python
numbers = [10, 20, 30, 20, 40]
numbers.remove(20)
print(numbers)
```

Результат:

```text
[10, 30, 20, 40]
```

Обратите внимание: удалено только первое число `20`. Если значения в списке нет, возникнет ошибка `ValueError`.

### 7.2. Метод `pop()`

Удаляет элемент по индексу и возвращает его значение.

```python
fruits = ["Apple", "Banana", "Cherry"]
deleted = fruits.pop(1)
print(deleted)
print(fruits)
```

Результат:

```text
Banana
['Apple', 'Cherry']
```

Если не указывать индекс, удаляется последний элемент:

```python
numbers = [10, 20, 30]
numbers.pop()
print(numbers)
```

Результат:

```text
[10, 20]
```

### 7.3. Оператор `del`

Удаляет элемент по индексу или несколько элементов с помощью среза.

```python
numbers = [10, 20, 30, 40]
del numbers[1]
print(numbers)
```

Результат:

```text
[10, 30, 40]
```

### 7.4. Метод `clear()`

Полностью очищает список.

```python
numbers = [10, 20, 30]
numbers.clear()
print(numbers)
```

Результат:

```text
[]
```

### Сравнение способов удаления

| Способ | Что делает |
|---|---|
| `remove(x)` | Удаляет первое вхождение значения `x` |
| `pop(i)` | Удаляет и возвращает элемент с индексом `i` |
| `pop()` | Удаляет и возвращает последний элемент |
| `del a[i]` | Удаляет элемент по индексу |
| `clear()` | Удаляет все элементы |

## 8. Поиск элементов в списке

### Оператор `in`

Позволяет проверить, содержится ли определённое значение в списке.

```python
students = ["Иван", "Мария", "Алексей"]

if "Мария" in students:
    print("Студент найден")
else:
    print("Студент не найден")
```

Результат:

```text
Студент найден
```

Также существует оператор `not in`:

```python
numbers = [10, 20, 30]

if 50 not in numbers:
    print("Число отсутствует")
```

### Метод `index()`

Возвращает индекс первого вхождения элемента.

```python
fruits = ["Apple", "Banana", "Cherry"]
position = fruits.index("Banana")
print(position)
```

Результат:

```text
1
```

Если элемента нет, возникнет ошибка `ValueError`. Поэтому перед поиском индекса полезно проверить наличие элемента:

```python
numbers = [10, 20, 30]
number = int(input("Введите число: "))

if number in numbers:
    print("Индекс:", numbers.index(number))
else:
    print("Число не найдено")
```

### Метод `count()`

Подсчитывает количество вхождений значения.

```python
grades = [5, 4, 5, 3, 5, 4]
print(grades.count(5))
```

Результат:

```text
3
```

Это полезно, например, для подсчёта количества определённых оценок.

## 9. Сортировка и изменение порядка элементов

### Метод `sort()`

Сортирует список по возрастанию.

```python
numbers = [8, 3, 10, 1, 5]
numbers.sort()
print(numbers)
```

Результат:

```text
[1, 3, 5, 8, 10]
```

Для сортировки по убыванию:

```python
numbers.sort(reverse=True)
print(numbers)
```

Результат:

```text
[10, 8, 5, 3, 1]
```

### Сортировка строк

```python
names = ["Мария", "Алексей", "Иван"]
names.sort()
print(names)
```

Результат:

```text
['Алексей', 'Иван', 'Мария']
```

### Функция `sorted()`

В отличие от `sort()`, функция `sorted()` создаёт новый отсортированный список, не изменяя исходный.

```python
numbers = [8, 3, 10, 1, 5]
result = sorted(numbers)
print(numbers)
print(result)
```

Результат:

```text
[8, 3, 10, 1, 5]
[1, 3, 5, 8, 10]
```

### Метод `reverse()`

Меняет порядок элементов на обратный.

```python
numbers = [10, 20, 30, 40]
numbers.reverse()
print(numbers)
```

Результат:

```text
[40, 30, 20, 10]
```

Важно объяснить, что `reverse()` **не сортирует** числа, а просто разворачивает существующий порядок.

## 10. Полезные встроенные функции для списков

| Функция | Описание | Пример результата |
|---|---|---|
| `len(a)` | Количество элементов | `5` |
| `sum(a)` | Сумма чисел | `25` |
| `max(a)` | Максимальный элемент | `10` |
| `min(a)` | Минимальный элемент | `1` |
| `sorted(a)` | Новый отсортированный список | `[1, 2, 3]` |
| `list()` | Создание списка | `[1, 2, 3]` |

Рассмотрим пример:

```python
numbers = [5, 10, 3, 8, 4]

print("Количество:", len(numbers))
print("Сумма:", sum(numbers))
print("Максимум:", max(numbers))
print("Минимум:", min(numbers))
```

Результат:

```text
Количество: 5
Сумма: 30
Максимум: 10
Минимум: 3
```

### Вычисление среднего арифметического

Формула:

\[
\text{Среднее} = \frac{\text{Сумма элементов}}{\text{Количество элементов}}
\]

```python
grades = [5, 4, 3, 5, 4]
average = sum(grades) / len(grades)
print("Средняя оценка:", average)
```

Результат:

```text
Средняя оценка: 4.2
```

Для пустого списка необходимо предусмотреть проверку, иначе при делении на ноль возникнет ошибка:

```python
if len(grades) > 0:
    average = sum(grades) / len(grades)
    print(average)
else:
    print("Список пуст")
```

# Часть 2. Списки и циклы

## 11. Перебор списка с помощью `for`

Очень часто необходимо выполнить какое-либо действие с каждым элементом списка. Например, вывести всех студентов.

```python
students = ["Иван", "Мария", "Алексей"]

for student in students:
    print(student)
```

Результат:

```text
Иван
Мария
Алексей
```

Здесь переменная `student` по очереди получает значение каждого элемента:

| Итерация | Значение `student` | Что выводится |
|---|---|---|
| 1 | `"Иван"` | Иван |
| 2 | `"Мария"` | Мария |
| 3 | `"Алексей"` | Алексей |

## 12. Перебор списка по индексам

Иногда необходимо не только получить значение элемента, но и узнать его индекс.

```python
students = ["Иван", "Мария", "Алексей"]

for i in range(len(students)):
    print(i, students[i])
```

Результат:

```text
0 Иван
1 Мария
2 Алексей
```

Такой способ особенно полезен при изменении элементов списка:

```python
numbers = [1, 2, 3, 4, 5]

for i in range(len(numbers)):
    numbers[i] = numbers[i] + 10

print(numbers)
```

Результат:

```text
[11, 12, 13, 14, 15]
```

### Функция `enumerate()`

Python предоставляет удобный способ одновременно получать индекс и значение.

```python
students = ["Иван", "Мария", "Алексей"]

for i, student in enumerate(students):
    print(i, student)
```

Можно начинать нумерацию с единицы:

```python
for i, student in enumerate(students, start=1):
    print(i, student)
```

Результат:

```text
1 Иван
2 Мария
3 Алексей
```

Это дополнительный материал: на первом занятии достаточно уверенного владения обычным `for`.

## 13. Перебор списка с помощью `while`

Цикл `while` тоже можно использовать для работы со списками.

```python
numbers = [10, 20, 30, 40]
i = 0

while i < len(numbers):
    print(numbers[i])
    i += 1
```

Результат:

```text
10
20
30
40
```

Здесь мы самостоятельно управляем индексом `i`.

# Часть 3. Практическая демонстрация

## 15. Программа «Список покупок»

Это хороший пример для демонстрации в классе, поскольку студенты уже знают циклы, условия и пользовательский ввод.

**Постановка задачи:** разработать программу, позволяющую управлять списком покупок.

Программа должна:

1. Показывать список покупок.
2. Добавлять новый товар.
3. Удалять товар по названию.
4. Проверять наличие товара.
5. Завершать работу по команде пользователя.

### Готовая программа

```python
shopping_list = []

while True:
    print("\n=== СПИСОК ПОКУПОК ===")
    print("1. Показать список")
    print("2. Добавить товар")
    print("3. Удалить товар")
    print("4. Найти товар")
    print("0. Выход")

    choice = input("Выберите действие: ")

    if choice == "1":
        if len(shopping_list) == 0:
            print("Список пуст")
        else:
            for product in shopping_list:
                print("-", product)

    elif choice == "2":
        product = input("Название товара: ")
        shopping_list.append(product)
        print("Товар добавлен")

    elif choice == "3":
        product = input("Какой товар удалить? ")

        if product in shopping_list:
            shopping_list.remove(product)
            print("Товар удалён")
        else:
            print("Товар не найден")

    elif choice == "4":
        product = input("Название товара: ")

        if product in shopping_list:
            print("Товар есть в списке")
        else:
            print("Товар отсутствует")

    elif choice == "0":
        print("До свидания!")
        break

    else:
        print("Неверная команда")
```

### Как объяснять программу студентам

Сначала создаём пустой список:

```python
shopping_list = []
```

Затем запускаем бесконечный цикл:

```python
while True:
```

Он позволяет пользователю выполнять несколько операций подряд.

Внутри цикла программа показывает меню и запрашивает команду.

- Если пользователь выбирает `2`, программа добавляет товар с помощью `append()`.
- Если выбирает `3`, программа сначала проверяет наличие товара через `in`, затем удаляет его с помощью `remove()`.
- Если выбирает `0`, выполняется `break`, завершающий цикл.

**Главная идея:** список хранит данные, а цикл и условия позволяют пользователю управлять этими данными.

# Часть 5. Типичные ошибки студентов

## Ошибка 1. Неправильный индекс

```python
numbers = [10, 20, 30]
print(numbers[3])
```

Ошибка: `IndexError`.

Правильно:

```python
print(numbers[2])
```

## Ошибка 2. Неправильное использование `append()`

```python
numbers = [1, 2, 3]
numbers = numbers.append(4)
print(numbers)
```

Результат будет `None`, поскольку `append()` изменяет существующий список и не возвращает новый.

Правильно:

```python
numbers = [1, 2, 3]
numbers.append(4)
print(numbers)
```

## Ошибка 3. Удаление отсутствующего значения

```python
numbers = [10, 20, 30]
numbers.remove(50)
```

Ошибка: `ValueError`.

Правильно:

```python
if 50 in numbers:
    numbers.remove(50)
```

## Ошибка 4. Путаница между `sort()` и `sorted()`

```python
numbers = [3, 1, 2]
result = numbers.sort()
print(result)
```

Результат:

```text
None
```

Метод `sort()` изменяет исходный список и возвращает `None`.

Правильно:

```python
numbers = [3, 1, 2]
result = sorted(numbers)
print(result)
```

## Ошибка 5. Изменение списка при переборе

```python
numbers = [2, 4, 6, 8]

for number in numbers:
    numbers.remove(number)
```

Так делать нежелательно: при удалении элементы сдвигаются, и цикл может пропускать значения.

Лучше создать новый список. Например, если нужно оставить только числа больше 4:

```python
numbers = [2, 4, 6, 8]
result = []

for number in numbers:
    if number > 4:
        result.append(number)

print(result)
```

Результат:

```text
[6, 8]
```
