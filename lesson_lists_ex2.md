# Практическая работа: Решение задач со списками в Python

**Тема:** Списки (`list`) в Python  
**Цель:** Научиться работать с элементами списков, изменять их, выполнять поиск, фильтрацию и обработку данных с помощью циклов и условий.

**Требования:** Каждую задачу выполнить в отдельной программе. Использовать списки, циклы `for` и `while`, условные операторы и изученные методы списков.

## Часть 1. Простые задачи

### Задание 1. Положительные и отрицательные числа

Дан список:

```python
numbers = [12, -5, 8, -3, 0, 17, -9, 4, -1, 6]
```

Напишите программу, которая:
- Подсчитывает количество положительных, отрицательных чисел и нулей.
- Находит сумму положительных чисел.
- Находит сумму отрицательных чисел.

### Задание 2. Поиск элементов

Дан список:

```python
numbers = [15, 28, 7, 42, 19, 33, 8, 56, 11]
```

Напишите программу, которая:
- Находит максимальное и минимальное число без использования `max()` и `min()`.
- Определяет индексы этих элементов.
- Вычисляет разницу между максимальным и минимальным числом.

### Задание 3. Изменение списка

Дан список:

```python
numbers = [4, 7, 12, 9, 16, 3, 20, 5]
```

Напишите программу, которая:
- Заменяет все чётные числа на `0`.
- Умножает все нечётные числа на `2`.
- Выводит изменённый список.

## Часть 2. Задачи среднего уровня

### Задание 4. Удаление повторений

Дан список:

```python
numbers = [4, 7, 4, 9, 2, 7, 5, 9, 1, 2, 8]
```

Создайте новый список, содержащий только уникальные элементы исходного списка.

**Условие:** Сохранить первоначальный порядок элементов. Не использовать `set()`.

Ожидаемый результат:

```python
[4, 7, 9, 2, 5, 1, 8]
```

### Задание 5. Второе наибольшее число

Дан список:

```python
numbers = [45, 12, 78, 34, 78, 56, 23, 90, 90, 67]
```

Найдите второе по величине **различное** число.

**Условие:** Не использовать `sort()` и `sorted()`.

Ожидаемый результат:

```text
Второе наибольшее число: 78
```

### Задание 6. Разделение списка

Дан список:

```python
numbers = [15, 22, 7, 18, 33, 40, 9, 12, 5, 26]
```

Создайте два новых списка:
- Первый содержит все чётные числа.
- Второй содержит все нечётные числа.

После этого выведите оба списка и определите, в каком больше элементов.

### Задание 7. Сдвиг элементов

Дан список:

```python
numbers = [10, 20, 30, 40, 50]
```

Напишите программу, которая сдвигает элементы списка на одну позицию вправо.

Последний элемент должен переместиться в начало списка.

Ожидаемый результат:

```python
[50, 10, 20, 30, 40]
```

**Дополнительно:** Реализуйте сдвиг на `k` позиций, где `k` вводит пользователь.

### Задание 8. Сравнение двух списков

Даны два списка:

```python
list1 = [4, 8, 15, 16, 23, 42]
list2 = [8, 16, 24, 42, 50, 60]
```

Напишите программу, которая:
- Создаёт список общих элементов.
- Создаёт список элементов, которые есть только в первом списке.
- Создаёт список элементов, которые есть только во втором списке.

Не использовать множества (`set`).

## Часть 3. Более сложные задачи

### Задание 9. Анализ оценок студентов

Дан список оценок:

```python
grades = [5, 4, 3, 5, 2, 4, 5, 3, 4, 2, 5, 4]
```

Напишите программу, которая:
- Подсчитывает количество каждой оценки от 2 до 5.
- Вычисляет средний балл.
- Определяет процент оценок «5».
- Определяет, сколько студентов получили оценку ниже среднего балла.

### Задание 10. Управление списком покупок

Создайте пустой список:

```python
products = []
```

Программа должна отображать меню:

```text
1. Добавить товар
2. Удалить товар
3. Найти товар
4. Показать все товары
5. Очистить список
0. Выход
```

**Требования:**
- Меню должно повторяться, пока пользователь не выберет `0`.
- При добавлении товара проверять, существует ли он в списке.
- При удалении проверять наличие товара.
- При поиске выводить индекс найденного товара.
- После каждой операции программа должна возвращаться в меню.

### Задание 11. Поиск самой длинной последовательности

Дан список:

```python
numbers = [2, 4, 6, 7, 8, 10, 12, 14, 3, 5, 8, 10, 12]
```

Найдите самую длинную последовательность **подряд расположенных в списке чётных чисел**.

Если максимальных последовательностей несколько, выведите первую найденную.

Ожидаемый результат:

```text
Самая длинная последовательность: [8, 10, 12, 14]
Длина: 4
```

### Задание 12. Мини-система учёта студентов

Создайте два списка:

```python
students = ["Анна", "Иван", "Мария", "Петр", "Олег"]
grades = [5, 3, 4, 2, 5]
```

Каждая оценка соответствует студенту с таким же индексом.

Реализуйте программу, которая:
- Выводит всех студентов с их оценками.
- Находит студентов с оценкой `5`.
- Позволяет изменить оценку выбранного студента.
- Позволяет добавить нового студента с оценкой.
- Позволяет удалить студента и соответствующую ему оценку.
- Определяет студента с наименьшей оценкой (если таких несколько — вывести всех).

**Важно:** При добавлении и удалении студентов соответствие индексов в двух списках должно сохраняться.
