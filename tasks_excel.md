### Задание 4. Формулы и относительная адресация

Необходимо рассчитать общую стоимость каждого товара.

Общая стоимость определяется как произведение цены товара на его количество.

1. Выберите ячейку F2.
2. Введите формулу:

```
=D2*E2
```

3. Нажмите Enter.
4. Скопируйте формулу на остальные строки с помощью маркера автозаполнения.
5. Проверьте, как изменяются адреса ячеек при копировании формулы.

При копировании формулы относительные адреса изменяются автоматически.

Под таблицей выполните дополнительные вычисления:

| Показатель                         | Функция    |
| ---------------------------------- | ---------- |
| Общее количество товаров на складе | `СУММ()`   |
| Общая стоимость всех товаров       | `СУММ()`   |
| Средняя цена товара                | `СРЗНАЧ()` |
| Максимальная цена                  | `МАКС()`   |
| Минимальная цена                   | `МИН()`    |
| Количество наименований товаров    | `СЧЁТЗ()`  |

### Задание 5. Абсолютная и смешанная адресация

#### 5.1 Абсолютная адресация

Магазин проводит акцию и предоставляет скидку на все товары.

1. В ячейку J1 введите текст «Скидка».
2. В ячейку K1 введите значение 15%.
3. В ячейке G2 рассчитайте цену товара со скидкой:

```
=D2*(1-$K$1)
```

4. Скопируйте формулу на остальные строки.
5. В ячейке H2 рассчитайте общую стоимость товара со скидкой:

```
=G2*E2
```

6. Скопируйте формулу на остальные строки.
7. Измените значение скидки с 15% на 20%.
8. Убедитесь, что стоимость всех товаров пересчиталась автоматически.

#### 5.2 Смешанная адресация

1. Создайте новый лист «Таблица умножения».
2. В диапазоне B1:K1 введите числа от 1 до 10.
3. В диапазоне A2:A11 введите числа от 1 до 10.
4. В ячейку B2 введите формулу:

```
=$A2*B$1
```

5. Используя автозаполнение, заполните весь диапазон B2:K11.

4. Отсортируйте товары по общей стоимости от большей к меньшей.
