# Домашнее задание по Python

## Задание 1. Создание словаря

Создайте словарь `student`, который содержит следующую информацию:

- `"name"` — `"Алексей"`
- `"age"` — `16`
- `"city"` — `"Москва"`

Выведите весь словарь на экран.

## Задание 2. Обращение по ключу

Дан словарь:

```python
car = {
    "brand": "Toyota",
    "model": "Camry",
    "year": 2020
}
```

Выведите отдельно:

1. Марку автомобиля.
2. Модель автомобиля.
3. Год выпуска.

## Задание 3. Создание словаря с помощью `dict()`

Создайте словарь `book` с помощью функции `dict()`.

Словарь должен содержать:

- `title` — `"Гарри Поттер"`
- `author` — `"Роулинг"`
- `year` — `1997`

Выведите полученный словарь.

## Задание 4. Словарь из списка

Дан список:

```python
data = [
    ["name", "Анна"],
    ["age", 18],
    ["city", "Казань"]
]
```

1. Преобразуйте список в словарь с помощью `dict()`.
2. Выведите полученный словарь.
3. Выведите только имя.

## Задание 5. Словарь из кортежей

Дан кортеж:

```python
products = (
    ("apple", 100),
    ("banana", 80),
    ("orange", 120)
)
```

1. Создайте словарь из кортежа с помощью `dict()`.
2. Выведите весь словарь.
3. Выведите цену банана.

## Задание 6. Пустой словарь

1. Создайте пустой словарь `person` с помощью `{}`.
2. Выведите его на экран.
3. Добавьте в словарь ключ `"name"` со значением `"Иван"`.
4. Добавьте ключ `"age"` со значением `20`.
5. Выведите полученный словарь.

## Задание 7. Информация о любимом фильме

Создайте словарь `movie`, содержащий:

- Название фильма.
- Жанр.
- Год выпуска.

Значения придумайте самостоятельно.

Выведите сначала весь словарь, затем отдельно название и жанр фильма.

## Задание 8. Самостоятельная работа

Создайте словарь `computer`, который содержит информацию о компьютере:

- `processor` — название процессора.
- `ram` — объём оперативной памяти.
- `storage` — объём накопителя.

Выполните следующие действия:

1. Создайте словарь.
2. Выведите весь словарь.
3. Выведите название процессора.
4. Выведите объём оперативной памяти.

---

**Требования к выполнению:** Каждое задание выполнить отдельно. Использовать только изученные способы работы со словарями. Циклы, условия и методы словарей пока не требуются.
