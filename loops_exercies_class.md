# Задачи по Python циклы

**Темы:** условия, циклы `for` и `while`, вложенные циклы, `break`, `continue`, `else`.

---

## Задача 1. Числа с условиями

**Условие:** Пользователь вводит числа `A` и `B`. Выведите все числа от `A` до `B`, которые делятся на 3, но не делятся на 5. В конце выведите их количество.

**Решение:**

```python
a = int(input("Введите A: "))
b = int(input("Введите B: "))

count = 0

for i in range(a, b + 1):
    if i % 3 == 0 and i % 5 != 0:
        print(i)
        count += 1

print("Количество:", count)
```

## Задача 2. Подсчёт положительных чисел

**Условие:** Пользователь вводит 10 целых чисел. Определите, сколько среди них положительных, отрицательных и нулей.

**Решение:**

```python
positive = 0
negative = 0
zeros = 0

for i in range(10):
    number = int(input("Введите число: "))

    if number > 0:
        positive += 1
    elif number < 0:
        negative += 1
    else:
        zeros += 1

print("Положительных:", positive)
print("Отрицательных:", negative)
print("Нулей:", zeros)
```

## Задача 3. Поиск числа

**Условие:** Пользователь вводит числа. Программа должна остановиться, когда пользователь введёт число `25`. Используйте `while` и `break`.

**Решение:**

```python
while True:
    number = int(input("Введите число: "))

    if number == 25:
        print("Число найдено!")
        break

    print("Попробуйте ещё раз")
```

## Задача 4. Пропуск чисел

**Условие:** Выведите числа от 1 до 30, пропуская числа, которые делятся на 4. Используйте `continue`.

**Решение:**

```python
for i in range(1, 31):
    if i % 4 == 0:
        continue

    print(i)
```

## Задача 5. Таблица умножения

**Условие:** Пользователь вводит число `N`. Выведите таблицу умножения от 1 до `N` с помощью вложенных циклов.

Например, для `N = 3`:

```text
1 2 3
2 4 6
3 6 9
```

**Решение:**

```python
n = int(input("Введите N: "))

for i in range(1, n + 1):
    for j in range(1, n + 1):
        print(i * j, end=" ")
    print()
```

## Задача 6. Прямоугольник из звёздочек

**Условие:** Пользователь вводит высоту и ширину прямоугольника. Выведите его с помощью вложенных циклов.

Пример для высоты 3 и ширины 5:

```text
*****
*****
*****
```

**Решение:**

```python
height = int(input("Высота: "))
width = int(input("Ширина: "))

for i in range(height):
    for j in range(width):
        print("*", end="")
    print()
```

## Задача 7. Прямоугольный треугольник

**Условие:** Пользователь вводит число `N`. Выведите треугольник из звёздочек.

Пример для `N = 4`:

```text
*
**
***
****
```

**Решение:**

```python
n = int(input("Введите N: "))

for i in range(1, n + 1):
    for j in range(i):
        print("*", end="")
    print()
```

## Задача 8. Поиск делителей

**Условие:** Пользователь вводит целое положительное число `N`. Выведите все его положительные делители и посчитайте их количество.

Например, для `N = 12`:

```text
1 2 3 4 6 12
Количество делителей: 6
```

**Решение:**

```python
n = int(input("Введите положительное число: "))
count = 0

for i in range(1, n + 1):
    if n % i == 0:
        print(i, end=" ")
        count += 1

print()
print("Количество делителей:", count)
```

## Задача 9. Проверка простого числа

**Условие:** Пользователь вводит число. Определите, является ли оно простым. Простое число больше 1 и делится без остатка только на 1 и само себя.

**Решение:**

```python
n = int(input("Введите число: "))

if n < 2:
    print("Число не является простым")
else:
    for i in range(2, n):
        if n % i == 0:
            print("Число не является простым")
            break
    else:
        print("Число простое")
```

## Задача 10. Сумма чисел в диапазоне

**Условие:** Пользователь вводит `A` и `B`. Найдите сумму всех чётных чисел между ними включительно.

**Решение:**

```python
a = int(input("Введите A: "))
b = int(input("Введите B: "))

total = 0

for i in range(a, b + 1):
    if i % 2 == 0:
        total += i

print("Сумма чётных чисел:", total)
```

## Задача 11. Числовой треугольник

**Условие:** Пользователь вводит число `N`. Выведите треугольник, в каждой строке которого числа начинаются с 1 и заканчиваются номером строки.

Пример для `N = 4`:

```text
1
12
123
1234
```

**Решение:**

```python
n = int(input("Введите N: "))

for i in range(1, n + 1):
    for j in range(1, i + 1):
        print(j, end="")
    print()
```

## Задача 12. Игра «Угадай число»

**Условие:** Загаданное число — `37`. Пользователь вводит числа, пока не угадает. Если число меньше загаданного, выведите `Мало`, если больше — `Много`. При правильном ответе завершите цикл через `break`.

**Решение:**

```python
secret = 37

while True:
    guess = int(input("Угадайте число: "))

    if guess == secret:
        print("Правильно! Вы угадали.")
        break
    elif guess < secret:
        print("Мало")
    else:
        print("Много")
```
