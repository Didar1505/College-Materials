# Практическая работа: Управление компьютером через Bash CLI

**Дисциплина:** Основы информационных технологий  
**Тема:** Терминал вместо мышки: основы командной строки Bash  
**Продолжительность:** 120–125 минут  
**Уровень:** Начальный  
**Формат:** Индивидуальная практическая работа

## Цель работы

Научиться управлять файлами и каталогами, работать с текстовой информацией, искать данные и объединять команды в терминале Bash.

**Правила выполнения:**

- Все задания выполняются только через терминал.
- Использовать графический файловый менеджер запрещено.
- Команды необходимо подбирать самостоятельно.
- После выполнения каждого блока преподаватель проверяет результат.
- Все операции с файлами выполняются в учебном каталоге.

## Подготовка к работе

Откройте терминал Bash и выполните:

```bash
mkdir -p ~/bash_lab
cd ~/bash_lab
```

Все дальнейшие задания выполняйте внутри `bash_lab`.

## Часть 1. Знакомство с терминалом и навигация

**15 минут · Задания 1–4**

### Задание 1. Где я нахожусь?

1. Определите текущий рабочий каталог.
2. Выведите список файлов и папок.
3. Выведите подробную информацию о содержимом каталога.
4. Отобразите скрытые файлы и папки.

**Результат:** студент должен уметь определить своё местоположение в файловой системе.

### Задание 2. Путешествие по файловой системе

1. Перейдите в домашний каталог пользователя.
2. Посмотрите его содержимое.
3. Перейдите в корневой каталог `/`.
4. Выведите список его содержимого.
5. Вернитесь в домашний каталог.
6. Перейдите обратно в `bash_lab`.

### Задание 3. Навигация без полного пути

1. Находясь в `bash_lab`, перейдите на один каталог выше.
2. Вернитесь в `bash_lab`, используя относительный путь.
3. Перейдите в домашний каталог одной командой.
4. Вернитесь в `bash_lab`, используя абсолютный путь.

### Задание 4. Исследование команд

С помощью встроенной справки Bash или руководства `man` выясните:

1. Для чего используется команда `ls -l`?
2. Чем отличается `ls -a` от `ls`?
3. Что означает `..` в пути?
4. Как вернуться в домашний каталог из любого места?

## Часть 2. Создание и управление файлами

**25 минут · Задания 5–10**

### Задание 5. Создание структуры колледжа

Создайте каталог `IT_College` и внутри него четыре папки:

- `Students`
- `Teachers`
- `Documents`
- `Backup`

Используйте только команды Bash.

**Ожидаемая структура:**

```text
IT_College/
├── Students/
├── Teachers/
├── Documents/
└── Backup/
```

### Задание 6. Организация студентов

Внутри папки `Students` создайте два каталога:

- `Group_01`
- `Group_02`

После этого перейдите в `Group_01` и выведите полный путь к текущему каталогу.

### Задание 7. Создание файлов

Создайте следующие пустые файлы:

| Файл | Где должен находиться |
|---|---|
| `anna.txt` | `Students/Group_01` |
| `boris.txt` | `Students/Group_02` |
| `contacts.txt` | `Teachers` |
| `schedule.txt` | `Documents` |

Проверьте наличие файлов через терминал.

### Задание 8. Копирование файлов

1. Скопируйте файл `schedule.txt` в папку `Backup`.
2. Создайте копию `anna.txt` с названием `anna_copy.txt` в той же папке.
3. Проверьте, что оригинальные файлы остались на месте.

### Задание 9. Перемещение и переименование

1. Переименуйте `contacts.txt` в `teachers.txt`.
2. Переместите `boris.txt` из `Group_02` в `Group_01`.
3. Переименуйте `anna_copy.txt` в `student_backup.txt`.
4. Убедитесь, что после перемещения файл `boris.txt` отсутствует в исходной папке.

### Задание 10. Удаление

1. Внутри `IT_College` создайте папку `Temp`.
2. Создайте в ней пустой файл `test.txt`.
3. Удалите файл `test.txt`.
4. Удалите пустую папку `Temp`.
5. Проверьте, что каталог больше не существует.

> **Внимание:** `rm` обычно удаляет файлы без помещения в корзину. Работайте только внутри учебного каталога и проверяйте путь перед удалением.

## Часть 3. Работа с текстовыми файлами

**20 минут · Задания 11–14**

### Задание 11. Создание расписания

Откройте каталог `Documents`.

С помощью `echo` и операторов перенаправления запишите в файл `schedule.txt` следующие строки:

```text
Monday: Bash
Tuesday: Python
Wednesday: Networking
Thursday: Databases
Friday: Cybersecurity
```

Условия:

- Первую строку запишите с помощью `>`.
- Остальные строки добавьте с помощью `>>`.
- Проверьте содержимое файла.

### Задание 12. Просмотр информации

Для файла `schedule.txt` выполните следующие операции:

1. Выведите всё содержимое файла.
2. Покажите только первые три строки.
3. Покажите только последние две строки.
4. Подсчитайте количество строк.
5. Выведите количество слов.

### Задание 13. Создание резервной копии

1. Скопируйте обновлённый `schedule.txt` в папку `Backup` под именем `schedule_new.txt`.
2. Добавьте в оригинальный файл строку `Saturday: Practice`.
3. Проверьте, что изменения появились только в оригинальном файле.
4. Определите количество строк в обоих файлах.

### Задание 14. Текстовый редактор

1. Откройте файл `Teachers/teachers.txt` с помощью `nano`.
2. Запишите три строки с именами преподавателей.
3. Сохраните изменения.
4. Закройте редактор.
5. Выведите содержимое файла в терминале.

## Часть 4. Поиск файлов и анализ информации

**25 минут · Задания 15–19**

### Задание 15. Поиск файлов

Находясь в `IT_College`:

1. Найдите все файлы с расширением `.txt`.
2. Найдите файл `students.txt`.
3. Найдите все файлы, в названии которых присутствует слово `backup`.
4. Найдите все файлы с расширением `.log`.
5. Определите, в каких каталогах находятся найденные файлы.

### Задание 16. Поиск ошибок сервера

Используя `server.log`:

1. Найдите все строки, содержащие `ERROR`.
2. Найдите все строки, содержащие `WARNING`.
3. Выведите ошибки вместе с номерами строк.
4. Найдите все строки, содержащие слово `Database`.

### Задание 17. Статистика ошибок

Определите:

1. Сколько строк содержат `ERROR`?
2. Сколько строк содержат `WARNING`?
3. Сколько строк содержат `INFO`?
4. Сколько всего строк находится в журнале?

**Запишите результаты для проверки преподавателем.**

### Задание 18. Поиск без учёта регистра

1. Найдите все строки, содержащие слово `error`, независимо от регистра.
2. Найдите все строки, содержащие слово `database`, независимо от регистра.
3. Сравните результаты обычного поиска и поиска без учёта регистра.

### Задание 19. Просмотр журнала

1. Выведите первые пять строк `server.log`.
2. Выведите последние три строки.
3. Определите, какая запись находится в начале журнала.
4. Найдите последнее сообщение об ошибке.
