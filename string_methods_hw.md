# Практическая работа. Методы строк в Python

**Тема:** Обработка и анализ текстовых данных  
**Уровень сложности:** Средний — повышенный  
**Продолжительность:** 90 минут

## Общие требования

- Использовать изученные методы строк, циклы, условные операторы, списки, индексы и срезы.
- Каждое задание выполнить в отдельной программе.
- Предусмотреть обработку некорректного ввода.
- Запрещено использовать регулярные выражения (`re`) и сторонние библиотеки.
- Все программы должны работать с различными пользовательскими данными, а не только с приведёнными примерами.

## Задание 1. Система регистрации пользователей

Разработайте программу регистрации пользователей.

Пользователь вводит имя, фамилию и желаемый логин.

**Требования:**

1. Удалить лишние пробелы в начале и конце каждого значения.
2. Привести имя и фамилию к формату с заглавной первой буквой.
3. Проверить логин по следующим правилам:
   - Длина от 6 до 15 символов.
   - Первый символ — латинская буква.
   - Остальные символы могут быть латинскими буквами, цифрами или `_`.
   - Логин не может содержать пробелы.
4. Если логин некорректен, вывести все обнаруженные ошибки.
5. Если логин корректен, сформировать профиль пользователя.

**Пример:**

```text
Введите имя:   иВАН
Введите фамилию:  пЕТРОВ
Введите логин: Ivan_2026

Регистрация успешна!

Имя: Иван
Фамилия: Петров
Логин: Ivan_2026
```

При некорректном логине:

```text
Введите логин: 2ab@

Ошибки:
- Логин слишком короткий
- Логин должен начинаться с латинской буквы
- Обнаружены недопустимые символы
```

## Задание 2. Анализатор текстовых сообщений

Напишите программу, которая анализирует введённый пользователем текст.

**Требования:**

1. Удалить лишние пробелы между словами.
2. Определить количество символов без пробелов.
3. Определить количество слов.
4. Найти самое длинное и самое короткое слово.
5. Определить количество слов, начинающихся с гласной буквы (русской или английской).
6. Найти все слова, которые встречаются более одного раза.
7. При сравнении слов игнорировать регистр и знаки `.`, `,`, `!`, `?` по краям слов.

**Пример:**

```text
Введите текст:
Python очень интересный язык Python простой язык

Количество слов: 7
Количество символов без пробелов: 43

Самое длинное слово: интересный
Самое короткое слово: язык
Слов, начинающихся с гласной: 2

Повторяющиеся слова:
Python — 2 раза
язык — 2 раза
```

**Дополнительное условие:** Если несколько слов имеют одинаковую минимальную или максимальную длину, вывести все такие слова.

## Задание 3. Обработка журнала событий

Система записывает события программы в следующем формате:

```text
2026-10-16 10:15:23 | INFO | User logged in
2026-10-16 10:16:05 | ERROR | Database connection failed
2026-10-16 10:17:12 | WARNING | Memory usage high
2026-10-16 10:18:44 | ERROR | Request timeout
2026-10-16 10:19:30 | INFO | User logged out
```

Создайте программу для анализа журнала.

**Требования:**

1. Разделить текст на отдельные записи.
2. Разделить каждую запись на дату, время, уровень события и сообщение.
3. Подсчитать количество событий каждого уровня (`INFO`, `WARNING`, `ERROR`).
4. Вывести только сообщения уровня `ERROR`.
5. Найти сообщения, содержащие введённое пользователем ключевое слово без учёта регистра.
6. Определить время последнего события с уровнем `ERROR`.

**Ожидаемый результат:**

```text
Всего событий: 5

INFO: 2
WARNING: 1
ERROR: 2

Ошибки:
10:16:05 — Database connection failed
10:18:44 — Request timeout

Последняя ошибка: 10:18:44
```

**Дополнительное условие:** Предусмотреть обработку некорректных записей, в которых отсутствует один из обязательных элементов.

## Задание 4. Проверка и исправление списка email-адресов

Пользователь вводит несколько email-адресов через точку с запятой.

Пример:

```text
Ivan@GMAIL.COM ; test@@mail.ru ; student@mail.com ;
admin@site ; hello world@gmail.com ; user123@company.org
```

Разработайте программу проверки адресов.

**Требования:**

1. Разделить введённую строку на отдельные адреса.
2. Удалить пробелы по краям каждого адреса.
3. Привести адреса к нижнему регистру.
4. Проверить каждый адрес:
   - Содержит ровно один символ `@`.
   - Имеет непустую часть до `@`.
   - Домен содержит хотя бы одну точку.
   - Домен не начинается и не заканчивается точкой.
   - Адрес не содержит пробелов.
   - Последняя часть домена после точки содержит минимум два символа.
5. Вывести корректные и некорректные адреса отдельно.
6. Исключить дубликаты корректных адресов.

**Пример результата:**

```text
Корректные адреса:
ivan@gmail.com
student@mail.com
user123@company.org

Некорректные адреса:
test@@mail.ru — несколько символов @
admin@site — отсутствует точка в домене
hello world@gmail.com — содержит пробел

Всего корректных: 3
Всего некорректных: 3
```

Проверка является учебной: реализовывать полный стандарт email не требуется.

## Задание 5. Поисковая система для текста

Разработайте простую поисковую систему, которая работает с одним большим текстом.

Пользователь вводит текст и поисковый запрос.

**Требования:**

1. Поиск должен игнорировать регистр.
2. Программа должна находить только отдельные слова, а не части других слов.
3. Вывести количество найденных совпадений.
4. Для каждого совпадения вывести номер слова в тексте (нумерация с 1).
5. Вывести предложение, в котором найдено совпадение.
6. Если совпадений нет, вывести соответствующее сообщение.

Считать, что предложения разделяются точками, а слова — пробельными символами. Запятые и знаки `!`, `?` по краям слов не учитываются.

**Пример:**

```text
Текст:
Python используется для разработки.
Многие программисты изучают Python.
Python очень популярен.

Поисковый запрос: python

Найдено совпадений: 3

1. Слово №1
   Python используется для разработки.

2. Слово №8
   Многие программисты изучают Python.

3. Слово №9
   Python очень популярен.
```

**Дополнительное условие:** Реализовать поиск фразы из нескольких слов, например `"изучают Python"`.

## Задание 6. Система проверки текстовых команд

Разработайте программу, которая принимает команды управления условным сервером.

Поддерживаемые команды:

```text
START server_name
STOP server_name
RESTART server_name
STATUS server_name
```

**Требования:**

1. Удалять лишние пробелы в командах.
2. Название команды распознавать без учёта регистра.
3. Проверять количество переданных аргументов.
4. Название сервера должно:
   - Содержать от 3 до 12 символов.
   - Состоять из латинских букв, цифр, `_` и `-`.
   - Начинаться с латинской буквы.
5. Выводить соответствующее сообщение для каждой корректной команды.
6. Для неизвестных команд и некорректных аргументов выводить описание ошибки.
7. Программа должна продолжать принимать команды, пока пользователь не введёт `EXIT`.

**Пример:**

```text
> START web_server

Сервер web_server запускается...

> status web_server

Запрошен статус сервера web_server

> STOP

Ошибка: не указано имя сервера

> RESTART 123server

Ошибка: имя сервера должно начинаться с буквы

> DELETE web_server

Ошибка: неизвестная команда

> EXIT

Завершение программы
```

Реально запускать и останавливать серверы не требуется — программа только распознаёт команды.

## Задание 7. Генератор сокращений и аббревиатур

Разработайте программу, которая автоматически формирует сокращения из названий организаций, проектов или учебных дисциплин.

**Требования:**

1. Получить от пользователя название.
2. Удалить повторяющиеся пробелы.
3. Исключить служебные слова:
   - Русские: `и`, `в`, `на`, `по`, `для`.
   - Английские: `and`, `of`, `the`, `for`.
4. Из оставшихся слов взять первые буквы.
5. Привести аббревиатуру к верхнему регистру.
6. Вывести исходное и обработанное название, а также аббревиатуру.
7. Если после удаления служебных слов не осталось ни одного слова, вывести ошибку.

**Пример 1:**

```text
Введите название:
Министерство науки и высшего образования

Обработанное название:
Министерство науки высшего образования

Аббревиатура: МНВО
```

**Пример 2:**

```text
Введите название:
The University of Information Technology

Обработанное название:
University Information Technology

Аббревиатура: UIT
```
