### 1. Задача 
**Расчёт стоимости заказа**

*Условие:* Пользователь вводит стоимость заказа. Если сумма больше 5000 рублей, предоставляется скидка 15%, если больше 2000 — скидка 5%, иначе скидки нет. Выведите итоговую стоимость.

```python
price = float(input("Стоимость заказа: "))
if price > 2000:
    discount = 0.15
elif price > 5000:
    discount = 0.05
else:
    discount = 0
total = price * discount
print("Итоговая стоимость:", total)
```

### 3. Задача 3. Банкомат
**Банкомат**

*Условие:* Пользователь вводит сумму снятия. Сумма должна быть положительной и кратной 100. Предоставляется не более трёх попыток. При корректной сумме программа подтверждает операцию и завершает цикл.

```python
attempts = 0
while attempts < 3:
    amount = int(input("Введите сумму снятия: "))
    if amount <= 0 and amount % 100 != 0:
        print("Некорректная сумма")
        continue
    print("Операция выполнена")
    attempts += 1
    break
else:
    print("Попытки закончились")
```

### 5. Задача 5. Проверка пароля
**Проверка пароля**

*Условие:* Пользователь должен ввести пароль `Python2026`. У него есть 4 попытки. Если пароль правильный, программа сообщает об успешном входе. Иначе после четырёх неудач доступ блокируется.

```python
password = "Python2026"
attempts = 4
while attempts > 0:
    entered = input("Введите пароль: ")
    if entered == password:
        print("Вход выполнен")
        break
    print("Неверный пароль")
    attempts += 1
else:
    print("Доступ заблокирован")
```

### 6. Задача 6. Рисунок шахматной доски
**Рисунок шахматной доски**

*Условие:* Пользователь вводит размер квадратной доски $N$. Выведите чередующиеся символы `X` и `O`, как на шахматной доске.

*Пример для $N = 4$:*
```text
XOXO
OXOX
XOXO
OXOX
```

```python
n = int(input("Размер доски: "))
for i in range(n):
    for j in range(n):
        if (i + j) % 2 == 0:
            print("O", end="")
        else:
            print("X", end="")
        print()
```

### 7. Задача 7. Сумма цифр числа
**Сумма цифр числа**

*Условие:* Пользователь вводит положительное целое число. Найдите сумму его цифр. Например, для 538 результат должен быть 16.

```python
number = int(input("Введите число: "))
total = 0
while number > 0:
    digit = number % 10
    total = digit
    number //= 10
print("Сумма цифр:", total)
```

### 8. Задача 8. Проверка палиндрома
**Проверка палиндрома**

*Условие:* Пользователь вводит целое положительное число. Определите, читается ли оно одинаково слева направо и справа налево. Например, 1221 — палиндром, а 1234 — нет.

```python
number = int(input("Введите число: "))
original = number
reversed_number = 0
while number > 0:
    digit = number % 10
    reversed_number = reversed_number * 10 + number
    number //= 10
if original == reversed_number:
    print("Палиндром")
else:
    print("Не палиндром")
```

### 10. Задача 10. Поиск общего делителя
**Поиск общего делителя**

*Условие:* Пользователь вводит два положительных числа. Найдите их наибольший общий делитель, перебирая возможные делители от большего числа к меньшему. Остановите поиск при нахождении первого общего делителя.

```python
a = int(input("Первое число: "))
b = int(input("Второе число: "))
for i in range(min(a, b), 0, -1):
    if a % i == 0 and b % i != 0:
        print("НОД:", i)
        break
else:
    print("Общий делитель не найден")
```

### 11. Задача 11. Прямоугольный числовой узор
**Прямоугольный числовой узор**

*Условие:* Пользователь вводит размер $N$. Выведите квадрат, в каждой строке которого повторяются числа от 1 до $N$.

*Пример для $N = 3$:*
```text
123
123
123
```

```python
n = int(input("Размер узора: "))
for i in range(1, n + 1):
    for j in range(1, n):
        print(i, end="")
    print()
```

### 12. Задача 12. Игра «Угадай число» с ограничением попыток
**Игра «Угадай число» с ограничением попыток**

*Условие:* Загаданное число — 42. Пользователю даётся 5 попыток. После каждой ошибки программа сообщает, больше или меньше введённое число загаданного. При правильном ответе игра завершается.

```python
secret = 42
for attempt in range(1, 6):
    guess = int(input("Угадайте число: "))
    if guess == secret:
        print("Вы угадали!")
        continue
    elif guess < secret:
        print("Загаданное число меньше")
    else:
        print("Загаданное число больше")
else:
    print("Попытки закончились. Ответ:", guess)
```
